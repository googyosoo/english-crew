# Activities — Project & Extension (프로젝트·심화 활동)

본문 너머로 확장되는 활동. 1차시를 넘기는 경우가 많고 산출물·발표가 핵심. 세특 연계에 강함.

각 활동: **목표 / 형태·시간 / 절차 / 학생용 자료 형식 / 학생용 자료 요소 / 교사용 가이드 요소 / 변형 / 본문 후크 활용**

---

## 1. Poster + Gallery Walk (포스터 + 갤러리 워크)

- **목표**: 본문 내용을 시각화 + 모둠 협력 + 발표·청중 활동
- **형태/시간**: 4인 모둠 / 35-50분 (1차시 또는 차시 분리 가능)
- **절차**: ①모둠별 본문 핵심 메시지 추출 (5분) → ②포스터 구성 결정 (Title / Visual / Key Points / Quote / Group's Message) → ③포스터 제작 (15-20분) → ④교실 벽에 게시 → ⑤모둠 1명만 자기 자리에 남고(설명자), 나머지는 다른 포스터 보러 이동 (Gallery Walk, 2분씩 5라운드) → ⑥자리 교대 → ⑦본인 모둠 자리로 → ⑧"가장 인상 깊은 포스터 1개와 그 이유" 적기
- **학생용 자료 형식**: 그래픽조직자 (포스터 기획안) + 별도 큰 종이/PPT 슬라이드
- **학생용 자료 요소**:
  - 포스터 기획안 (A4 1장):
    - Title 칸 (5단어 이내)
    - Visual 스케치 칸
    - Key Points 칸 (3개 글머리)
    - Quote 칸 (본문에서 직접 인용 1문장)
    - Our Group's Message 칸 (1문장)
  - Gallery Walk 메모 칸: 라운드별 [Group / What I learned / 1 question]
- **교사용 가이드 요소**: 모둠 역할 분담 (Designer / Writer / Speaker / Critic 4역) / 시간 관리 (제작 20분 넘기지 않기) / 발표자 멘트 가이드 ("This poster shows...") / 평가 관찰 포인트 (협력·시각화·메시지 전달력)
- **변형**: 디지털 포스터 (Canva 등), 1page summary 형식
- **본문 후크 활용**: 시각화 가능한 본문(설명문·체험기·내러티브) 강함. 추상적 논설문은 시각화 어려움 — 인포그래픽 형식으로 변형

---

## 2. Mini-Debate (미니 토론)

- **목표**: 본문 쟁점을 찬·반으로 나눠 토론, 영어 논증 능력 강화
- **형태/시간**: 4-8인 / 35-45분
- **절차**: ①교사가 본문에서 토론 명제 1개 추출 (e.g., "Technology improves human relationships") → ②찬·반 모둠 배정 (개인 의견과 무관하게) → ③각 모둠 5분 입론 준비, 5분 반론 준비 → ④입론 (찬 2분 / 반 2분) → ⑤반론 (찬 2분 / 반 2분) → ⑥자유 토론 5-7분 → ⑦청중 투표 / 또는 자기 입장 다시 결정
- **학생용 자료 형식**: 워크시트 (토론 노트)
- **학생용 자료 요소**:
  - 명제 박스 + 배정된 입장 표시
  - Opening Statement 칸 (입론, 3-4문장)
  - Counter-Arguments 예상 칸 (상대 측이 할 만한 말)
  - Rebuttal Notes 칸 (반론용 메모)
  - Useful expressions 박스: "I would argue that...", "On the other hand...", "However, we should consider...", "The text says..."
  - 본문 근거 인용 칸 (line ___)
- **교사용 가이드 요소**: 토론 명제 작성 가이드 (찬·반이 균등하게 가능한 명제) / 시간 관리 (입론 2분, 반론 2분 엄수, 발화자 교대) / 4-corner 변형 (4가지 입장에서 학생 자유 이동) / 평가 관찰 포인트 (논거의 본문 기반성, 영어 표현, 청취·반응)
- **변형**: 4-corner debate (Strongly Agree / Agree / Disagree / Strongly Disagree 코너에 학생 이동) / Silent debate (글로만 주고받기)
- **본문 후크 활용**: 논쟁 가능한 본문(논설문·이슈 기반 내러티브) 강함. 사실·정보 중심 본문은 부적합

---

## 3. Concept Map (개념 지도)

- **목표**: 본문 핵심 개념·관계를 시각화하여 통합 이해
- **형태/시간**: 개인 또는 짝 / 20-30분
- **절차**: ①본문 1독 → ②핵심 개념 8-12개 추출 → ③중심에 핵심 주제 → 가지로 개념 연결 → ④개념 간 관계를 화살표 + 동사로 표시 (e.g., "causes", "leads to", "is part of") → ⑤짝과 비교
- **학생용 자료 형식**: 그래픽조직자
- **학생용 자료 요소**:
  - 빈 동심원 또는 자유 그리기 영역 (A4 가로)
  - 중심 노드 안내 (가운데 큰 동그라미)
  - 핵심 개념 추출 칸 (10개 슬롯, 단어/구로 적기)
  - Linking words 박스 (causes / results in / is similar to / is opposite to / depends on / is part of)
  - 짝 비교 박스: "What concept did your partner add that you missed?"
- **교사용 가이드 요소**: 개념 추출 가이드 (명사·동명사 위주, 추상도 한 단계 위로) / 모범 지도 1개 / 평가 관찰 포인트 (개념 다양성·관계 정확성·통합성)
- **변형**: 모둠 큰 종이 1장 (협력형), Mind map (자유 가지) vs Concept map (관계 명시) 선택
- **본문 후크 활용**: 설명문·논설문·과학 본문에 강함. 단순 사건 내러티브에는 5W1H Map이 더 적합

---

## 4. Cross-Reading (다른 텍스트와 비교)

- **목표**: 본문을 다른 텍스트와 비교 분석 (주제·관점·장르·시대)
- **형태/시간**: 짝 또는 4인 모둠 / 1차시 + 차시 후 보고서 (분리 권장)
- **절차**: ①교사가 비교 텍스트 1편 제시 (또는 학생이 검색) → ②두 텍스트 각각 핵심 메시지 추출 → ③Venn diagram 또는 T-chart로 공통점·차이점 정리 → ④2-3문단 비교 글쓰기 → ⑤모둠 공유
- **학생용 자료 형식**: 그래픽조직자 + 워크시트 (글쓰기)
- **학생용 자료 요소**:
  - Text A / Text B 핵심 추출 칸
  - Venn diagram (공통점 가운데, 차이점 양쪽)
  - "Which text is more persuasive? Why?" 분석 칸
  - 비교 글쓰기 칸 (3 paragraphs: Both / Different / My take)
  - 비교 어휘 박스: "similarly / in contrast / whereas / both texts argue"
- **교사용 가이드 요소**: 비교 텍스트 추천 (같은 주제 다른 입장 / 같은 사건 다른 시대 / 같은 장르 다른 문체) / 짧은 비교 텍스트(150단어 이하) 우선 / 평가 관찰 포인트 (분석 깊이·근거 인용·구조)
- **변형**: 본문 vs 학생 자작 텍스트, 본문 vs 영상 자료
- **본문 후크 활용**: 논쟁·관점 본문에 강함. 세특 연계 보고서로 확장 가능

---

## 5. PSA Script (공익 광고 대본)

- **목표**: 본문 메시지를 30초 공익 광고 대본으로 재구성 (창의·압축·전달성)
- **형태/시간**: 2-4인 모둠 / 1차시 + 차시 후 발표·녹화 (분리 권장)
- **절차**: ①본문에서 사회적 메시지·교훈 추출 → ②30초 대본 구조 결정 (Hook 5s / Problem 10s / Solution or Call 10s / Tagline 5s) → ③대본 작성 → ④역할 분담 + 리허설 → ⑤발표 (생, 또는 영상 녹화 후 상영)
- **학생용 자료 형식**: 워크시트 (대본 양식)
- **학생용 자료 요소**:
  - Message Statement 칸 (한 문장, 우리 PSA가 전하려는 것)
  - Target Audience 칸
  - 4단 대본 칸:
    - Hook (5초): 시선 끄는 장면·질문
    - Problem (10초): 본문에서 가져온 문제 묘사
    - Solution / Call to Action (10초)
    - Tagline (5초): 기억할 한 문장
  - 시각·음향 큐 칸 (Stage Directions)
  - Useful tagline patterns 박스 ("Don't ___, do ___.", "It's time to ___.", "Because every ___ matters.")
- **교사용 가이드 요소**: 모둠 역할 (Writer / Director / Actor / Camera) / 30초 시간 엄수 / 평가 관찰 포인트 (메시지 명료성·창의성·전달력) / 안전·저작권 안내 (음악·이미지 사용 시)
- **변형**: 라디오 광고 (음성만), 인쇄 광고 (포스터 변환)
- **본문 후크 활용**: 사회적·윤리적 메시지가 있는 본문(환경·건강·인권·기술 등) 강함

---

## 6. 세특 연계 보고서 (Subject Record-Linked Report)

- **목표**: 본문 주제를 학생 진로·관심사와 연결하여 1-2쪽 보고서 작성. 세특(과세특) 기록 자료로 활용.
- **형태/시간**: 개인 / 차시 후 과제 (1주일)
- **절차**: ①본문 핵심 주제 확인 → ②자기 진로·관심사와 연결점 발굴 → ③추가 자료 1-2편 조사 → ④보고서 작성 (Introduction / Connection to My Interest / What I Learned / Future Inquiry) → ⑤제출 → ⑥교사 코멘트·세특 기록 반영
- **학생용 자료 형식**: 워크시트 (보고서 양식)
- **학생용 자료 요소**:
  - Title 칸
  - Introduction 칸 (3-4문장, 본문 요약 + 본 보고서가 다룰 것)
  - Connection to My Interest 칸 (5-6문장, 진로·관심사와의 연결)
  - What I Learned 칸 (5-6문장, 새로 알게 된 것 + 추가 자료에서 배운 것)
  - Future Inquiry 칸 (3-4문장, 더 알고 싶은 것 + 어떻게 알아볼지)
  - References 칸 (자료 출처 1-2개, 형식 자유)
  - Self-Check 박스: ☐ 본문 직접 인용 1회 이상 ☐ 추가 자료 1-2편 ☐ 진로·관심사 연결 명시 ☐ 분량 1-2쪽
- **교사용 가이드 요소**: 평가/기록 가이드 (영어 정확성보다 주제 의식·탐구성 우선) / 세특 작성 시 활용할 관찰 포인트 (탐구 주제 명료성, 자료 활용, 자기 진로 연결, 후속 질문의 깊이) / 모범 보고서 1개 / 학생이 자료 못 찾을 때 추천할 검색 키워드 / 한국어 일부 허용 여부 결정 (영어 보고서 원칙이지만 단어 수준에서 한국어 단어 1-2개 보조 허용 등)
- **변형**: 모둠 보고서 (4명 협력), 발표형 (보고서 → 5분 발표)
- **본문 후크 활용**: 모든 학문적·사회적 주제 본문에 적용 가능. 진로 다양한 학급에서 효과 큼

---

## 카테고리 공통 가이드

- **차시 분리 권장**: 프로젝트·심화 활동은 1차시 안에 끝내려 하지 말 것. "도입·기획 → 제작 → 발표·정리" 3단계로 2-3차시에 걸쳐 운영하면 질이 올라간다.
- **평가 루브릭 별도**: 산출물에 점수를 매기려면 [내용 / 영어 / 협력 / 발표] 4축 5점 척도 루브릭을 교사용 가이드에 첨부한다.
- **세특 연계**: 한국 고교 맥락에서 프로젝트 활동은 세특 기록 자료로 가치가 크다. 교사용 가이드의 "관찰 포인트"를 세특 키워드(탐구·연계·태도·성장)로 정리한다.
- **시간 관리 신호**: 길어지기 쉬우므로 "남은 시간 5분", "마무리 1분" 같은 신호를 명확히 약속한다.
- **저작권/안전**: 영상·이미지 사용 시 학생 동의·저작권 확인. 발표 영상은 학교 정책 따라 처리.
