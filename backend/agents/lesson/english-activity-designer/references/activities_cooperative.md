# Activities — Cooperative & Games (협력·게임 활동)

짝/모둠/반 전체가 협력하거나 경쟁하며 본문을 다루는 활동. 분위기 환기와 참여 독려에 강함.

각 활동: **목표 / 형태·시간 / 절차 / 학생용 자료 형식 / 학생용 자료 요소 / 교사용 가이드 요소 / 변형 / 본문 후크 활용**

---

## 1. Jigsaw Reading (직소 리딩)

- **목표**: 본문 분할 → 모둠별 책임 학습 → 전체 통합. 모든 학생이 능동적 화자가 됨.
- **형태/시간**: 4-6인 모둠 / 30-40분
- **절차**: ①본문을 4개 부분으로 분할 → ②"홈 모둠" 4명에게 부분 1/2/3/4 각각 배정 → ③같은 부분끼리 모인 "전문가 모둠"에서 5-7분 깊이 읽기 + 정리 → ④홈 모둠으로 복귀 → ⑤각자 자기 부분을 모둠원에게 영어로 설명 → ⑥전체 흐름 통합 워크시트 완성 → ⑦교사 확인 퀴즈 5문항
- **학생용 자료 형식**: 워크시트 + 분할된 본문 4종 (인쇄 시 4가지 색지 권장)
- **학생용 자료 요소**:
  - "Your Section" 분할 본문 (4종 별지)
  - Expert Notes 칸 (전문가 모둠에서 채움): Key idea / Key vocab / 1 question
  - Home Group Worksheet (홈 모둠에서 채움): 4부분 모두 들어갈 격자
  - Final Quiz 5문항 (교사 확인용)
- **교사용 가이드 요소**: 본문 분할 가이드 (논리·시간 단위로 자르고 단락 길이 균등화) / 모둠 구성 (홈 4명, 전문가 6-8명) / 시간 표시 (전문가 7분, 홈 발표 8분, 통합 5분) / 영어 발화 부담 학생 대처 (전문가 모둠에서 한국어 토의 → 홈 모둠에서 영어 발표 패턴 허용)
- **변형**: 부분이 5-6개일 때 5-6인 모둠, 정의·예시·결과 같은 논리 단위 분할
- **본문 후크 활용**: 본문이 길고 (300+ 단어) 논리 단위로 분할 가능할 때 가장 강함. 짧고 통합적인 내러티브에는 부적합

## 2. Hot Seat (인물 인터뷰)

- **목표**: 본문 인물 입장 추론 + 즉흥 영어 발화
- **형태/시간**: 4-5인 모둠 / 20-25분
- **절차**: ①모둠에서 1명을 본문 인물로 지목 ("Hot Seat") → ②나머지가 인물에게 영어 질문 → ③Hot Seat 학생은 인물 입장에서 답 → ④3-5분 후 역할 교대 → ⑤모둠당 가장 인상 깊은 질문·답을 1세트 골라 발표
- **학생용 자료 형식**: 카드세트 (질문 카드) + 워크시트 (메모용)
- **학생용 자료 요소**:
  - 질문 카드 (잘라 쓰기): 6-8장 미리 준비된 질문 카드 + 빈 카드 4장 (학생이 만든 질문)
    - 미리 준비된 질문 예: "How did you feel when ___?", "What did you mean by ___?", "If you could go back, would you ___?", "Why didn't you ___?"
  - Hot Seat 학생용 메모 칸: 인물의 핵심 가치·말투 단서를 본문에서 메모
  - 모둠 베스트 Q&A 기록 칸
- **교사용 가이드 요소**: 인물 추출 가이드 (갈등이 있는 인물 우선) / 답변 시 "I think the character would say..."도 허용 / 영어로 답하기 어려운 학생은 한국어로 답한 뒤 짝이 영어 통역 / 평가 관찰 포인트 (질문의 깊이, 인물 입장 일관성)
- **변형**: Press Conference (한 인물 vs 반 전체 기자), 두 인물 동시 인터뷰
- **본문 후크 활용**: 인물의 갈등·결정·감정이 명확한 내러티브·전기에 가장 강함

---

## 3. Vocabulary Bingo (어휘 빙고)

- **목표**: 핵심 어휘 인지·청해 강화
- **형태/시간**: 개인 (반 전체 함께 진행) / 10-15분
- **절차**: ①교사가 본문 어휘 25개 제시 → ②학생이 5×5 칸에 자기 마음대로 배치 → ③교사가 정의·예문·동의어 중 하나로 단어 호출 → ④학생이 해당 단어 칸 표시 → ⑤Bingo 외치기
- **학생용 자료 형식**: 카드세트 (Bingo 카드 1장)
- **학생용 자료 요소**:
  - 25개 단어 풀 박스 (Word Pool)
  - 5×5 빈 격자 (Free 칸 1개 표시)
  - 호출된 단어 기록란 (5줄)
- **교사용 가이드 요소**: 호출 방식별 난이도 (단어 그대로 < 한국어 뜻 < 영어 정의 < 예문 빈칸 < 동의어/반의어) / 호출 순서 / Bingo 보상 (스티커·간식 등 학교 정책 따라)
- **변형**: 뜻 빙고(영어 정의로 호출), 모둠 빙고(모둠 1장 함께)
- **본문 후크 활용**: 본문 어휘가 25개 이상 핵심어로 추출 가능할 때. 도입(Pre-reading)에 사용하면 본문 읽기 전 어휘 노출 효과 큼

---

## 4. Quiz Quiz Trade (짝 어휘 카드 교환)

- **목표**: 어휘·핵심 정보를 짧고 빠르게 반복 점검 (반복 횟수 = 학습 횟수)
- **형태/시간**: 짝 (반 내 자유 이동) / 10-15분
- **절차**: ①학생이 카드 1장 받음 (앞=영, 뒤=한) → ②짝과 만남 → ③서로 카드 보여주고 묻기 → ④맞히면 카드 교환 → ⑤다른 짝 찾기 → ⑥4-5분 후 종료, 마지막 받은 카드 5개 확인
- **학생용 자료 형식**: 카드세트 (반 인원수만큼)
- **학생용 자료 요소**: A6 크기 카드 30장. 앞면=영어 단어/구, 뒷면=한국어 뜻 + 본문 출처 문장 (잘라 쓰기 좋게 표 형식 인쇄)
- **교사용 가이드 요소**: 카드 인쇄·재단 안내 (얇은 색지 + 코팅 권장) / "Excuse me, do you have a moment?" 같은 만남 멘트 안내 / 일어나서 자유 이동 규칙 / 시간 종료 시 마지막 카드 5개 어휘 확인
- **변형**: 어휘 → 본문 사실 (Q&A 카드), 짝 활동 → 모둠 활동 (모둠 안에서 교환)
- **본문 후크 활용**: 어휘 풍부 본문. 본문 핵심어 + 동의어/반의어 섞어 카드 만들면 더 효과적

---

## 5. Information Gap (정보 격차 활동)

- **목표**: 짝이 가진 정보가 다르므로, 영어로 묻고 답해야 정보 통합 가능
- **형태/시간**: 짝 / 15-20분
- **절차**: ①Student A·B 활동지 배포 (서로 다름) → ②서로 자기 정보 보여주지 않고 영어로 묻기 → ③빠진 칸 채워 완성 → ④교사 확인
- **학생용 자료 형식**: 워크시트 2종 (Student A / Student B)
- **학생용 자료 요소**:
  - Student A 시트: 본문 정보의 절반 + 빈칸 절반 (B에게 물어 채울 곳)
  - Student B 시트: A의 빈칸 부분이 채워져 있고, A가 채운 부분이 비어 있음
  - Useful questions 박스 ("What time...?", "Where did...?", "How many...?")
  - "Don't show your paper!" 안내
- **교사용 가이드 요소**: 본문에서 사실·수치·시간 등 정보 추출 → 절반씩 분할 가이드 / 카드 모양 인쇄 추천 / 영어 발화 부담 학생을 위해 첫 1-2개 질문 예시
- **변형**: 인물 프로필 격차, 시간표·일정 격차, 지도·위치 격차
- **본문 후크 활용**: 정보·사실 풍부 본문(설명문·안내문·인터뷰)에 가장 강함. 추상적 논설문에는 부적합

---

## 6. Find Someone Who (사람 찾기)

- **목표**: 반 전체와 영어로 짧게 묻고 답하기
- **형태/시간**: 반 전체 (자유 이동) / 10-15분
- **절차**: ①학생이 8-10개 항목이 있는 시트 받음 ("Find someone who agrees with the author / has been to ___ / can name 3 vocabulary words from the text" 등) → ②반 친구들과 만나 영어로 묻기 → ③조건 맞으면 친구 이름 적기 (한 명당 1-2칸까지만) → ④5-7분 후 자리로 → ⑤모둠 또는 반 전체와 결과 공유
- **학생용 자료 형식**: 워크시트
- **학생용 자료 요소**: 8-10개 진술 + Name 적는 칸 + Useful question starter 박스 ("Have you ever...?", "Do you think...?", "Can you...?")
- **교사용 가이드 요소**: 진술 작성 가이드 (본문 관련 + 학생 일상 경험 섞기) / 한 친구를 1-2칸까지만 사용 규칙 / 결과 공유 방법 (4-5명 호명 후 결과 발표)
- **변형**: 반 → 모둠 안 (인원 적은 반에서)
- **본문 후크 활용**: 본문 주제와 학생 경험을 잇는 진술 만들 때 효과적. 도입 활동으로 강함

---

## 7. Running Dictation (달리는 받아쓰기)

- **목표**: 읽기·기억·받아쓰기 통합 + 신체 활동
- **형태/시간**: 짝 (한 명 reader, 한 명 writer) / 15-20분
- **절차**: ①교사가 본문 짧은 발췌(5-7문장)를 교실 벽 4-6곳에 게시 → ②짝 중 reader는 벽으로 달려가 한 번에 한 문장 외움 → ③writer에게 와서 영어로 말함 → ④writer가 받아쓰기 → ⑤끝나면 역할 교환 또는 다음 문장 → ⑥완성 후 본문 원본과 대조
- **학생용 자료 형식**: 워크시트 (받아쓰기용 줄종이) + 벽 게시용 발췌문 4-6장 (교사 준비)
- **학생용 자료 요소**:
  - Writer's worksheet: 가로줄 7-10줄 + Reader's name 칸 + Self-check 칸 (스펠링·문법 표시)
  - 벽 게시용 발췌문 (학생용 자료에는 포함 안 됨, 교사용 가이드에 인쇄 첨부)
- **교사용 가이드 요소**: 안전 안내 (뛰지 말고 빠르게 걷기) / 발췌문 선정 가이드 (5-7문장, 핵심 단락 추천) / 벽 게시 위치 분산 (혼잡 방지) / 평가 관찰 포인트 (협력·정확성·인내)
- **변형**: 모둠 4인 (1 reader, 3 writers — runner 교대), 반대로 writer가 외쳐주기 등
- **본문 후크 활용**: 짧고 명확한 본문(150 단어 이하), 대화문·안내문에 강함. 긴 본문은 일부 발췌해 사용

---

## 8. Reader's Theater (역할 낭독)

- **목표**: 본문을 대본화·낭독 → 발음·억양·감정 표현 연습
- **형태/시간**: 2-4인 모둠 / 25-35분
- **절차**: ①본문을 대본 형식으로 변환 (Narrator + Characters) → ②모둠별 역할 배정 → ③5-10분 연습 → ④모둠별 낭독 → ⑤청중 피드백 (좋았던 점 1, 인상 깊었던 표현 1)
- **학생용 자료 형식**: 워크시트 (대본 형식)
- **학생용 자료 요소**:
  - 대본 (Narrator: ___ / Character A: ___) — 5-10페이지 분량
  - 역할별 highlight 안내 (Character A는 노란색 등)
  - Performance Notes 칸 (감정·동작·억양 메모)
  - Audience feedback 칸 (다른 모둠 보고 적기)
- **교사용 가이드 요소**: 본문 → 대본 변환 가이드 (직접 인용은 그대로, 서술은 Narrator 대사로) / 발음·억양 모델링 / 평가 관찰 포인트 (전달성·협력·창의성) / 영상 촬영 옵션 (학생 동의 후)
- **변형**: 즉흥 연기 추가 / Narrator 없이 대화만 (대화문 풍부할 때) / 시 낭송형
- **본문 후크 활용**: 대화·내러티브 풍부 본문에 강함. 설명문·논설문은 변환 부담 큼 — 부적합

---

## 카테고리 공통 가이드

- **이동·소음 관리**: 협력·게임 활동은 시끄럽다. 사전에 "이 활동은 신호(○분)에 종료합니다", "옆 반 방해 안 되게 voice level 2" 등 신호 약속 해 두면 진행이 매끄럽다.
- **모둠 구성**: 4명 모둠이 협력 활동의 표준. 6명은 무임승차 위험, 2명은 협력감 약함.
- **공평 참여 확보**: 카드 활동·Jigsaw·Hot Seat는 역할이 명시적이라 잘 작동. 자유 토의는 공평성 깨지기 쉬우므로 발화 카운터·역할 표찰 등 보조 도구 사용.
- **카드 인쇄 안내**: 카드세트가 들어간 활동지는 활동지 끝 페이지에 점선 가이드와 함께 카드를 인쇄. 학생 본인용 작성 부분과 분리해서 한 번 출력으로 활용 가능하게 한다.
