# Output Formats — 학생용 자료 형식별 docx 구조

학생용 활동지의 docx 구조는 활동 유형에 따라 4가지 중 하나를 선택한다. 각 활동의 reference 파일에 "학생용 자료 형식: ___" 표시로 어떤 형식인지 명시되어 있다.

**반드시 `/mnt/skills/public/docx/SKILL.md` 를 먼저 읽고 그 가이드에 따라 docx를 생성한다.** 아래는 각 형식의 구조·필수 요소·시각적 가이드라인이다.

---

## 형식 1. Worksheet (워크시트)

**언제 사용**: 이해 확인 활동 대부분 / 산출 활동 / Information Gap / Running Dictation의 writer 시트 / 보고서

**구조** (위→아래 순서):
1. **Header 박스** (표 1행 4열): School / Grade / Class·No / Name (Date 옵션)
2. **활동명** (제목 1, 영문) + 한국어 부제 (제목 2)
3. **Activity Goal** (한 줄 안내, 영어 또는 영·한 병기)
4. **Time** (예: ⏱ 20 minutes)
5. **본문 발췌** (필요 시, 박스 처리 + 작은 글씨)
6. **Instructions** (번호 매김, 영어 + 한국어 병기 권장)
7. **활동 본체** (활동별 reference에 명시된 요소들 — 빈칸·표·답안 칸 등)
8. **Self-Check 또는 Pair Check 칸** (활동 끝)
9. **Footer**: "Time's up?", 평가 안내 한 줄

**시각 가이드**:
- 글꼴: Calibri 11 (영문) / 맑은 고딕 11 (국문). 제목은 14-16
- 답안 작성 칸: 한 줄 답 → underscoring `__________`, 여러 줄 → 가로줄 표 (1열 N행)
- 박스: 본문 발췌·Useful expressions·Word Bank 등은 1행 1열 표(테두리 굵게 0.5pt)
- 여백: 좌우 2.5cm, 상하 2cm 정도. 너무 빽빽하게 쓰지 말 것

## 형식 2. Card Set (카드세트)

**언제 사용**: Quiz Quiz Trade / Hot Seat 질문 카드 / Vocabulary Bingo (보드형) / Order the Events 카드형

**구조**:
1. **상단 안내** (1쪽 분량): 활동명 + 사용법 ("아래 카드를 점선을 따라 잘라 사용하세요" + 영문 병기)
2. **카드 그리드** (2-3쪽 분량):
   - 한 페이지에 6-12장 카드 (A6 또는 A7 크기 권장)
   - 표 (3열 × 4행 = 12장 패턴 권장)
   - 셀 안: 카드 본문 (단어, 정의, 질문, Bingo 격자 등)
   - **점선 안내** (셀 경계): 표 테두리는 점선 또는 굵은 실선, 셀 안은 일정한 패딩
3. **(양면 카드 필요 시)**: 앞면 페이지 + 뒷면 페이지 (앞면이 영어, 뒷면이 한국어 같은 구조). 인쇄 후 뒷면을 정렬해 출력해야 함을 안내문에 명시

**시각 가이드**:
- 카드 최소 크기: 6cm × 9cm (A7) — 손에 잡기 좋고 잘라 쓰기 좋음
- 카드 안 글씨: 14pt 이상 (멀리서도 보이도록)
- Bingo 격자: 5×5 칸, 셀 크기 2cm × 2cm 이상, 빈 칸 (학생이 채울 수 있게)
- **반드시 "잘라 쓰는 가이드 점선" 안내**: 활동지 제일 위에 ✂️ 또는 "Cut along the dotted lines" 명시

## 형식 3. Graphic Organizer (그래픽조직자)

**언제 사용**: 5W1H Map / Concept Map / Venn Diagram / Cross-Reading T-chart / Poster 기획안

**구조**:
1. **상단 헤더 박스**: Header (학생 정보) + 활동명
2. **Goal & Time** (한 줄)
3. **Instructions** (3-4줄)
4. **조직자 본체**: 활동별로 모양이 다름
   - **5W1H Map**: 6칸 격자 (2행 3열) + 하단 "One-Sentence Summary" 줄
   - **Concept Map**: A4 가로 배치 권장. 중심 노드 큰 동그라미 + 주변 빈 공간 (학생이 직접 그림)
     - 워드 표로 동심원 흉내 가능 (가운데 큰 셀, 테두리 둥글게 처리)
     - 또는 빈 박스 + 안내 텍스트 ("중앙에 본문의 핵심 주제를 쓰고, 가지로 뻗어 나가며 개념을 적으세요")
   - **Venn Diagram**: 2개 교차 원. docx에서는 표로 흉내 — 3열(왼쪽 only / 공통 / 오른쪽 only) 또는 SmartArt
   - **포스터 기획안**: A4 1장에 5칸 (Title / Visual / Key Points / Quote / Group Message)
5. **자기 점검 / 짝 점검** 칸

**시각 가이드**:
- 가로 방향 페이지(landscape) 고려 (Concept Map, Venn)
- 칸 크기: 학생이 충분히 쓸 수 있도록 큰 셀 (최소 4cm × 4cm)
- Linking words 박스: 페이지 하단에 작은 박스로 (학생이 참고용으로 보도록)
- 손글씨 영역이 많은 형식이므로 줄·격자 안내선만 두고 빈 공간을 충분히 둘 것

## 형식 4. Slide-Style (슬라이드형)

**언제 사용**: 발표·게시 목적 산출물 (Poster의 디지털 버전, PSA 대본 발표용 큐카드)

**구조**:
- 가로 방향(landscape) docx, 큰 글씨, 페이지당 정보 1단위
- 페이지 1: Title slide (활동명·모둠명·인원)
- 페이지 2-N: 핵심 내용 슬라이드 (한 페이지 = 한 메시지)
- 마지막 페이지: Q&A 또는 Thank you

**시각 가이드**:
- 글꼴 크기: 24pt 이상 (제목 36-44, 본문 24-28)
- 한 슬라이드에 글머리 5개 이내, 8단어 이내/줄
- 시각 요소 자리 표시 (이미지 들어갈 자리 박스 + "Insert image here / 이미지 자리")
- 학생이 바로 PowerPoint·Canva로 옮길 수 있도록 단순한 구조 유지

## 형식 선택 결정 트리

```
활동이 카드 교환·Bingo·잘라 쓰는 카드인가?
  └─ Yes → Card Set
  └─ No → 활동이 시각적 도식 중심인가? (Map / Diagram / Poster 기획)
        └─ Yes → Graphic Organizer
        └─ No → 활동이 발표·게시 산출물인가?
              └─ Yes → Slide-Style
              └─ No → Worksheet (기본값)
```

활동별 reference의 "학생용 자료 형식" 표기를 그대로 따르면 된다. 위 트리는 새로운 활동이나 변형을 만들 때 형식을 결정하는 기준이다.

## 공통 적용 사항 (모든 형식)

1. **이름 적는 칸은 항상 첫 페이지 상단**: 모둠 활동이면 모둠원 4명 이름 모두 적는 칸 둘 것
2. **페이지 수 표시**: 2쪽 이상이면 "1/3" 형식 페이지 번호 푸터에
3. **잘라 쓰는 부분이 있으면 반드시 ✂️ 표시**: 학생이 헷갈리지 않게
4. **답안 칸의 너비·높이 일관성**: 같은 종류의 답에는 같은 칸 크기. 들쑥날쑥하면 학생이 답의 분량을 잘못 가늠
5. **국·영 병기 원칙**: 핵심 지시문(Instructions, Self-Check)은 영·한 병기. 작은 안내(Useful expressions 박스 안 등)는 영어만
6. **인쇄 친화성**: 흑백 인쇄해도 가독성 유지 (색만으로 정보 구분 금지). 색이 들어가면 회색으로도 구분 가능하게 음영 처리
7. **여백**: 좌우 2.5cm, 상하 2cm. 노트 정리 공간 확보 (학생이 옆에 메모할 수 있게)

## 교사용 가이드 docx 구조 (모든 활동 공통)

학생용 자료와 별개로 **교사용 진행 가이드** docx는 형식이 통일되어 있다:

1. **Header**: 활동명·학년/과목·차시·작성일 (자동 생성)
2. **활동 개요** (1단락): 학습목표·소요시간·필요물품·사회적 형태(개인/짝/모둠)
3. **시간 배분 표**: 도입(○분) / 전개(○분) / 정리(○분) — 표 형식
4. **단계별 진행** (각 단계마다):
   - 교사 발화 예시 (영어 + 한국어 병기)
   - 교사 행동 (학생 모둠 돌기, 시간 신호 등)
   - 학생 활동 (간단히 설명)
5. **모범답안 / 예시답안**: 학생 활동지의 답안 칸에 들어갈 예시
6. **예상 어려움 + 대처 카드**: 표 (어려움 / 대처법) — 최소 3개 행
   - 흔한 어려움: 영어 발화 부담, 모둠 갈등, 시간 초과, 무임승차, 본문 이해 부족
7. **평가·관찰 포인트**: 무엇을 보고 무엇을 기록할지. 세특 키워드 후보 명시.
8. **변형 옵션 1-2개**: 같은 활동을 어떻게 다르게 운영할 수 있는지

각 활동 reference의 "교사용 가이드 요소"에 명시된 항목을 모두 포함한다.
