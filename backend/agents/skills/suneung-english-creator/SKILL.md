# 수능 영어 문제 제작 스킬

이 스킬은 대한민국 대학수학능력시험(수능) 영어 영역 문제를 제작합니다.

## 사용 방법

### 1단계: 문제 유형 확인

사용자가 요청한 문제 유형을 확인하고, 해당 유형의 특징을 파악합니다.

**주요 유형:**
- **빈칸추론** (31-34번, 3점): 가장 고난도, 논리적 추론 필요
- **주제파악** (23번, 2점): 글 전체를 아우르는 중심 내용
- **요지파악** (22번, 2점): 필자가 전달하려는 핵심 메시지
- **제목파악** (24번, 2점): 글을 함축하는 제목
- **무관한 문장** (35번, 2점): 흐름에 맞지 않는 문장 찾기
- **글의 순서** (36번, 2점): 문단 배열
- **문장 삽입/위치** (37-39번, 2점): 적절한 위치 찾기
- **요약문 완성** (40번, 3점): A, B 빈칸 완성
- **기타**: 목적, 심경, 주장, 함의, 어휘, 문법, 내용일치 등

유형별 세부 정보는 `references/question_types.md` 참조.

### 2단계: 지문 제작

#### 길이 기준
- 쉬운 유형(목적, 심경, 주장): 100-120단어
- 중간 유형(주제, 요지, 제목): 130-150단어
- 빈칸추론: 150-200단어
- 장문: 300-400단어

#### 내용 구성
1. **명확한 주제**: 하나의 중심 아이디어
2. **논리적 전개**: 서론-본론-결론 또는 문제-해결 구조
3. **적절한 예시**: 추상적 개념을 구체화
4. **연결어 활용**: however, therefore, moreover, for example 등

#### 문장 구조
- 평균 문장 길이: 15-25단어
- 복문과 중문 혼합
- 관계사절, 분사구문 등 다양한 문법 요소 포함
- 지나치게 복잡한 구조는 피하기

#### 어휘 수준
- 고등학교 교육과정 범위
- 학술적이지만 전문적이지 않은 수준
- 어려운 단어는 문맥으로 유추 가능하게

### 3단계: 문제 제작

#### 유형별 전략

**빈칸추론:**
1. 지문의 핵심 논리 구조 파악
2. 빈칸 위치 결정 (보통 중심 문장)
3. 빈칸 전후로 대조/인과 관계 설정
4. 선택지 제작:
   - 정답: 논리적으로 정합
   - 오답: 부분적으로 관련되나 논리적으로 맞지 않음
   - 매력적 오답 포함 (학생들이 자주 선택할 만한)

**주제/요지/제목:**
1. 전체 내용을 압축한 선택지 (정답)
2. 부분만 다룬 선택지 (오답)
3. 관련 있지만 초점이 다른 선택지 (오답)
4. 지문에 언급되지 않은 내용 (오답)
5. 지나치게 포괄적이거나 구체적인 선택지 (오답)

**무관한 문장:**
- 전체 흐름: A-B-C-D-E
- 무관한 문장 삽입 위치: 주로 중간 (③번 선택지)
- 무관한 문장: 주제와 관련되지만 논리적으로 연결 안 됨

**글의 순서:**
1. 주어진 글에서 화제 제시
2. (A): 세부 설명 또는 예시
3. (B): 전환 또는 추가 정보
4. (C): 결론 또는 함의
5. 지시어(this, that, such), 연결어 활용

**요약문 완성:**
1. 지문 전체를 2문장으로 압축
2. A와 B는 상호보완적 관계
3. 각 빈칸당 5개 선택지 (총 25개 조합 중 정답 1개)

### 4단계: 선택지 검토

**필수 검토 사항:**
- [ ] 정답이 명확하게 하나만 존재하는가?
- [ ] 오답이 완전히 틀렸는가 (부분 정답 없음)?
- [ ] 매력적 오답이 포함되어 있는가?
- [ ] 선택지 길이가 비슷한가?
- [ ] 문법적으로 자연스러운가?

### 5단계: 해설 작성

**해설 구조:**
```
【정답】 ②

【해설】
1. 핵심 논리: [지문의 중심 논리 구조 설명]
2. 단서: [정답 도출의 핵심 단서]
3. 정답 근거: [왜 ②가 정답인지]
4. 오답 분석:
   ① [왜 틀렸는지]
   ③ [왜 틀렸는지]
   ④ [왜 틀렸는지]
   ⑤ [왜 틀렸는지]

【어휘】
- 핵심 어휘 3-5개 정리
```

## 출제 원칙

1. **교육과정 준수**: 고등학교 교육과정 범위 내 출제
2. **논리적 사고력 측정**: 단순 암기가 아닌 이해와 추론
3. **공정성**: 특정 배경지식 불필요
4. **변별력**: 상위권과 중위권 구분 가능
5. **실용성**: 실생활 관련 소재 포함

## 주제 선정 가이드

**적합한 주제:**
- 교육, 심리학, 사회학
- 환경, 생태, 지속가능성
- 기술, 과학, 혁신
- 문화, 예술, 역사
- 경제, 경영, 조직 행동
- 건강, 운동, 웰빙

**피해야 할 주제:**
- 정치적으로 민감한 내용
- 종교적 논쟁
- 지나치게 전문적인 내용
- 특정 국가/민족 편향
- 최신 시사 (날짜가 특정되는 내용)
