# 시험지 레이아웃 참고 (원안지 hwpx 기준)

**실제 시험지 파일은 `scripts/build_exam.py` 가 `assets/templates/영어II_원안지.hwpx`
를 복제해서 만든다.** 이 문서는 docx 시절의 레이아웃 메모가 아니라, 문항 내용을
작성할 때(Step 3) 참고할 서식 규칙만 정리한 것이다. 실제 조립 방법은
`references/hwpx_build_guide.md` 를 본다.

## 안내 문구 (자동 처리됨)

```
○ 해당란에 과목코드, 번호 등을 정확히 기입, 표기하시오.
○ 문항마다 배점이 다르니 각 물음의 끝에 있는 배점을 참고하시오.
○ 전체 문항 수는 선택형(N문항), 서술형(M문항)이며 총 (N+M)문항입니다.
```
문항 수는 `build_exam.py` 가 spec.json의 questions 배열 길이로 자동 계산해 넣는다.
직접 손댈 필요 없음.

## 문항 번호 (자동 처리됨)

- 객관식: 문서 자동 번호(개요 번호) — **stem 텍스트에 "1." 같은 번호를 넣지 않는다.**
- 선택지: ①②③④⑤ 도 대부분 자동 번호(문단 스타일)다. `plain_choice5` 유형은
  choices 텍스트에 번호를 넣지 않는다.
- 서술형: `【서술형 1】`, `【서술형 2】` — build_exam.py가 자동으로 붙인다. stem에
  직접 넣지 않는다.
- 지문 속 원형숫자(①②③④⑤, 어법/무관한 문장/삽입용)는 리터럴 문자이며
  `embedded_underline`/`marker_passage`/`insertion` 빌더가 자동으로 붙인다.

## 배점 표기

- 발문 끝에 `[3점]` `[3.5점]` `[4점]` `[4.5점]` 등 대괄호로 직접 stem 텍스트에 포함시킨다
  (이건 자동화되지 않으므로 Step 3에서 반드시 넣을 것).
- 서술형은 `[6점]`, `[7점]`, `[8점]`. 소문항이 있으면 `(2점)`, `(3점)` 처럼 소괄호.

## 각주/주석

어려운 어휘는 지문 바로 아래 별도 문단으로 `*어휘 뜻   **어휘 뜻` 형식
(builder의 `gloss` 파라미터).

## 박스 표기

- `< 조 건 >`, `<Word Box>`: 테두리 박스(1x1 표) — `word_box` 빌더가 자동 처리.
- 삽입 유형의 "주어진 문장"도 동일한 테두리 박스로 자동 처리.

## 서술형 답란 줄 수 표준 (R2, num_answer_lines 파라미터로 지정)

| 서술형 유형 | 답란 줄 수 |
|---|---|
| 우리말 해석 | 4-6줄 |
| 함축 의미 우리말 서술 | 3-4줄 |
| Word Box 영작 / 조건부 영작 | 2-3줄 |
| 단어 찾기(영영 정의) | 1줄 |
| 어법 오류 + 이유 | 항목당 2-3줄 |
| 대명사 지칭 | 1줄 |

답란이 너무 짧으면 학생이 답을 쓸 수 없다. **반드시 위 표를 지킬 것.**

## 헤더/푸터 정보

`meta` 객체(school/grade/semester/exam_name/subject/total_pages)로 지정한다.
비워두면 예시 파일의 원래 값(심인고/2학년/2학기/중간고사/영어II)이 그대로 남으므로,
**실사용 시 반드시 채운다.**
