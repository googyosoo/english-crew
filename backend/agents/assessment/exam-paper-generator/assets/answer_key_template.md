# 정답·해설지 템플릿 (Answer Key & Explanation)

시험지와 별도 docx 파일로 생성. 채점·검토용으로 자세한 근거와 해설 포함.

## 전체 구조

```
[학년] [학기] [시험명] [과목명] 정답·해설

────────────────────────────────────────────────────

[총평]
- 총 문항 수: (N+M)문항 (객관식 N + 서술형 M)
- 배점 합계: 100점 (객관식 X점 + 서술형 Y점)
- 난이도 분포: 상 (a)문항, 중 (b)문항, 하 (c)문항
- 출제 의도: (간단 요약 - 학습 단원/주제 등)

────────────────────────────────────────────────────

【객관식】

═══════════════════════════════════════════════════
문항 1 │ 정답 ⑤ │ 난이도 [하] │ 유형: 요지 파악 │ 배점 3점
═══════════════════════════════════════════════════

[근거 문장]
"Believing they were closer to the reward, they were more
motivated to reach the finish line."

[해설]
지문은 카페 보상카드 실험을 통해 "출발선에서 미리 진척된 듯한
인식"이 동기를 강화함을 보여준다. 따라서 정답은 ⑤.

[오답 분석]
① 보상 시스템으로 행동을 바꾸기 어렵다 → 글의 결론과 반대.
② 보상 크기의 차이가 목표 달성 속도에 영향 → 글은 보상 크기가
   아닌 '인식된 진척'을 다룸.
③ 복잡한 단계의 보상은 회피 → 본문에 언급 없음.
④ 일관된 혜택 프로그램이 신뢰 유지 → 본문 주제와 무관.

═══════════════════════════════════════════════════
문항 2 │ 정답 ③ │ 난이도 [중] │ 유형: 주제 파악 │ 배점 3점
═══════════════════════════════════════════════════

...

────────────────────────────────────────────────────

【서술형】

═══════════════════════════════════════════════════
서술형 1 │ 난이도 [중] │ 유형: 우리말 해석 │ 배점 6점
═══════════════════════════════════════════════════

[모범답안]
"이 두 역할이 비슷해 보일 수 있다는 사실에도 불구하고,
실제로는 꽤 다른 책임을 가지고 있다."

[근거 문장]
"Despite the fact that these two roles may appear similar,
they actually have quite different responsibilities."

[채점 기준]
- "Despite the fact that": 양보 표현 정확 (+2점)
- "may appear similar": 조동사 + 보어 정확 (+1점)
- "quite different responsibilities": 어휘+의미 정확 (+2점)
- 자연스러운 한국어 어순/표현 (+1점)

[감점 사례]
- "Despite" 단순 "그럼에도" 처리 (-1점)
- "may"를 단정문으로 해석 (-1점)
- 핵심 어휘 (responsibilities) 누락 (-2점)

═══════════════════════════════════════════════════
서술형 2 │ 난이도 [중] │ 유형: 표 빈칸 + 함축 의미 │ 배점 7점
═══════════════════════════════════════════════════

(1) 표 빈칸 (4점, 부분점수 있음)
- ① memories
- ② structure
- ③ expectations
- ④ normal
(각 1점)

(2) cocktail party script 의미 (3점, 부분점수 있음)
[모범답안]
"칵테일파티에서 일반적으로 일어나는 일에 관한 사전 지식 구조
(스키마)로, 새 이야기를 이해할 때 기준이 되는 틀."

[채점 기준]
- "사전 지식/스키마 구조" 언급 +1점
- "이해의 기준/틀" 기능 언급 +1점
- 한국어 표현 자연스러움 +1점

────────────────────────────────────────────────────

[부록] 정답 일람표

| 문항 | 정답 | 배점 | 난이도 | 유형 |
|---|---|---|---|---|
| 1 | ⑤ | 3 | 하 | 요지 |
| 2 | ③ | 3 | 중 | 주제 |
| ... | | | | |

[부록] 출처 / 지문 주제 일람

| 문항 | 지문 주제 | 단어 수 |
|---|---|---|
| 1 | 카페 보상카드 실험 (Kivetz) | 165 |
| ... | | |
```

## 작성 원칙

1. **근거 문장 인용**: 객관식 모든 문항은 지문에서 정답 근거가 되는 문장(또는 구절)을 **그대로** 인용한다. 추론 문항은 종합 근거를 2-3문장 인용.

2. **오답 분석**: 객관식은 4개 오답 모두에 대해 "왜 오답인가"를 1줄씩 설명. 매력 오답에는 더 상세히.

3. **서술형 채점 기준**: 부분점수 있음을 명시하고, 각 핵심 요소에 점수 분배. 자주 나올 감점 사례도 포함.

4. **창의 유형 표시**: `유형: 창의 (C-N)` 또는 `유형: 창의 (CD-N)` 형식으로 표시.

5. **난이도 라벨**: `난이도 [상]`, `난이도 [중]`, `난이도 [하]`. 대괄호 사용.

6. **부록 정답 일람표**: 채점 시 빠른 확인용. 문항 번호/정답/배점/난이도/유형 5열.

## docx 작성 시 스타일

- 문항 구분선은 박스 또는 굵은 가로선
- 정답은 **굵게** + 색상 강조 가능 (빨강 또는 파랑)
- "근거 문장"은 *기울임* 또는 인용 블록
- 표는 docx의 표 기능 사용
