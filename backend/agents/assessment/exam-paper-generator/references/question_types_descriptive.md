# 서술형 문항 유형 표준 (Descriptive Question Types)

심인고 1학년 공통영어 4개 시험지 서술형 1~5번 패턴 분석. 표준 시험지에서는 5문항이며 각 문항은 (1), (2) 소문항 1-3개로 구성될 수 있다.

## 목차

1. 우리말 해석 (Translation to Korean)
2. 영영사전 정의 매칭 (Word Definition)
3. Word Box 단어 배열 영작 (Word Order)
4. 표·요약 빈칸 채우기 (Fill-in Summary Table)
5. 우리말 의미 영작 (Korean → English with Conditions)
6. 어법 오류 찾고 고치기 (Grammar Error Identification)
7. 학생 발화 중 틀린 내용 고르기 (Student Statement Critique)
8. 대명사 지칭 대상 (Pronoun Reference)
9. 함축 의미 우리말 서술 (Implied Meaning in Korean)
10. 조동사 + have + p.p / 가정법 변형 (Modal Perfect / Conditional)
11. 핵심 영어 문장 구성 - 조건부 영작 요지 (Topic Sentence Construction)

---

## 1. 우리말 해석

- **발문**: `다음 밑줄 친 문장을 우리말로 해석하시오.`
- **형식**: 본문 안 밑줄 친 문장(주로 복합구조 - 분사구문/관계사절/가정법) → 한국어 해석.
- **채점**: 부분점수 있음. `<조 건>` 박스에 "핵심 단어가 빠지거나 잘못 해석한 경우 감점" 명시.
- **배점**: 6점 (중)
- **적합 지문**: 한 문장 내에 1-2개의 문법 포인트가 있는 복합문 포함 글
- **예시**: 시험지1-1 서술형1 (docent와 curator 대조 글의 한 문장 해석)

## 2. 영영사전 정의 매칭

- **발문**: `다음 영영사전 뜻풀이에 해당하는 단어를 본문에서 찾아 쓰시오.`
- **형식**: 영영 정의 2-4개 + 품사 표시 + 본문에서 단어 찾아 쓰기. 부분점수 있음.
- **배점**: 2-3점 (하-중)
- **예시**: 시험지1-1 서술형3 ((v) "to become known or regarded as something" → emerge)

## 3. Word Box 단어 배열 영작

- **발문**: `Word Box 속 표현을 바르게 배열하여 윗글의 요지를 완성하시오.` 또는 `밑줄 친 우리말과 같은 뜻이 되도록 Word Box 안 단어들을 어순에 맞게 바르게 배열하시오.`
- **형식**:
  - `<Word Box>` 안에 단어/구 8-15개 슬래시(/)로 구분
  - `<조 건>`: ① Word Box의 단어를 빠짐없이 한 번씩 사용 ② 단어의 어형 변화 금지 (또는 밑줄 친 단어만 변형 허용)
- **배점**: 4-8점 (중-상)
- **예시**: 시험지2-1 서술형5 (`In a team / included / when ...` 배열)

## 4. 표·요약 빈칸 채우기

- **발문**: `다음은 윗글을 요약한 표이다. ① ~ ④에 알맞은 단어를 Word Box에서 찾아 그대로 완성하시오.`
- **형식**: 본문 요약 표(Main Idea / Process / Example 등) + 빈칸 4개 + Word Box(8-12 단어).
- **배점**: 4점 (중)
- **예시**: 시험지1-1 서술형2(1) (Schank & Abelson "understanding" 요약표)

## 5. 우리말 의미 영작 (조건부)

- **발문**: `다음 글의 밑줄 친 우리말과 의미가 같도록 <조건>에 따라 Word Box 안 단어들을 어순에 맞게 바르게 배열하시오.` 또는 `<조건>에 맞게 영어로 쓰시오.`
- **형식**: 본문에 한국어로 표시된 부분 → 영작
  - `<조 건>` 예시: "1. 아래 단어만 사용할 것 / 2. 밑줄 친 단어만 변형하고 나머지는 변형하지 말 것"
- **배점**: 3-6점 (중-상)
- **예시**: 시험지1-2 서술형5 (frighten / interfere with / fear / frequently 등 사용)

## 6. 어법 오류 찾고 고치기

- **발문**: `윗글 ⓐ ~ ⓗ 중 어법상 틀린 부분이 있는 문장의 기호를 N개 찾아 쓰시오.` + `선택한 문장 중 틀린 부분을 찾아 바르게 고치고 그 이유를 설명하시오.`
- **형식**: 본문 문장 ⓐⓑⓒ… 표시 / 학생이 N개(주로 2-4개) 골라 수정 + 문법적 이유 설명
- **이유 설명 예시**: "지시대명사가 가리키는 명사가 복수형이므로 those가 적절함"
- **배점**: 5-8점 (상)
- **예시**: 시험지1-1 서술형5(2), 시험지1-2 서술형4(3)

## 7. 학생 발화 중 틀린 내용 고르기

- **발문**: `윗글의 내용 중 밑줄 친 부분을 읽고, 다음 중 틀린 내용을 말하는 친구의 이름을 모두 골라 쓰시오.` + `(2) 틀린 부분을 <보기>를 참고해 이유를 들어 설명하시오.`
- **형식**: 본문 + 학생 5-6명 발화(이름 + 문법/내용 분석 발언). 학생 중 1-3명이 틀린 분석을 함.
- **출제 포인트**: 어법, 지시어, 수동태/능동태, to-부정사 용법 구분, 동격/관계사 구분
- **배점**: 6-7점 (상)
- **예시**: 시험지1-1 서술형5 (민지/수진/현우/태양/지훈/은서)

## 8. 대명사 지칭 대상

- **발문**: `다음 글에서 밑줄 친 대명사 ⓐ, ⓑ, ⓒ가 가리키는 대상을 우리말로 쓰시오.`
- **형식**: 본문 안 대명사(she, them, their 등) → 지칭하는 명사구를 한국어로.
- **배점**: 3점 (중) 부분점수 있음
- **예시**: 시험지1-1 서술형1 (Brooks 실험 → ⓐ She: Brooks, ⓑ them: 흥분 그룹, ⓒ their: 통제 집단의)

## 9. 함축 의미 우리말 서술

- **발문**: `윗글의 밑줄 친 [표현]이 문맥적으로 의미하는 바를 우리말로 서술하시오.`
- **형식**: 본문 안 비유/은유 표현 → 한국어로 풀어 쓰기. 부분점수 있음.
- **배점**: 2-3점 (중)
- **예시**: 시험지1-1 서술형2(2) (`cocktail party script` → "칵테일파티에서 보통 일어나는 일에 대한 사전 지식 구조")

## 10. 조동사 + have + p.p / 가정법 변형

- **발문**: `빈칸 (A)에 단어 [원형]을 변형하여 '조동사+have+p.p' 형태로 적으시오.` 또는 가정법 과거 표현 사용 영작.
- **형식**: 단어 1개 제시 → 후회/추측/비난 의미의 조동사 완료 형태로 변형 (예: ask → should have asked).
- **배점**: 3점 (중)
- **예시**: 시험지1-1 서술형4(1) (ask → should have asked)

## 11. 요지 영작 (핵심 영어 문장 구성)

- **발문**: `다음 글의 요지를 <조건>에 맞게 영어로 쓰시오.`
- **형식**: 본문 + 시작어("When") 제시 + Word Box(7-10단어) + 조건(어형 변형 규칙).
- **배점**: 6점 (상)
- **예시**: 시험지1-2 서술형5 (When + frequently + fear + frighten + infants + interfere with + the social development → "When infants are frightened frequently, fear interferes with the social development of infants.")

## 표준 5문항 구성 가이드

서술형 5문항은 다음 분포가 이상적:

| 번호 | 추천 유형 | 난이도 | 배점 |
|---|---|---|---|
| 서술형 1 | 1 (해석) 또는 8 (대명사) | 중 | 6점 |
| 서술형 2 | 4 (요약 표) + 9 (함축) 결합 | 중 | 7점 |
| 서술형 3 | 2 (영영 정의) + 3 (Word Box 배열) 결합 | 중 | 7점 |
| 서술형 4 | 6 (어법 오류) 또는 10 (변형 영작) | 상 | 8점 |
| 서술형 5 | 7 (학생 발화) 또는 11 (요지 영작) | 상 | 6-7점 |

서술형 5문항 중 **창의 유형 1개까지** 허용 (`creative_types.md` 참조).

## 채점 기준 명시 (필수)

모든 서술형은 정답·해설지에 다음을 명시한다:

1. **모범답안**: 1-2개 (복수 정답 허용 시 모두 기재)
2. **부분점수 기준**: 핵심 어휘/구조별 배점 분배 (예: 어형 변형 정확 +1, 어순 정확 +1, 의미 일치 +1)
3. **감점 사례**: 자주 나올 만한 오답 + 감점 폭

예시:
```
[서술형 4 (1)] 모범답안: should have asked
- ask 원형 사용: +1
- should have + p.p 형태: +2
- 감점: have asked (조동사 누락) -1, asked (변형 자체 안함) -3
```

## HWPX 조립 매핑 (scripts/build_exam.py 의 type 값)

| # | 유형 | build_exam.py type | 비고 |
|---|---|---|---|
| 1 | 우리말 해석 | `translation_blank` | num_answer_lines로 답란 줄 수 조절(4-6줄 권장) |
| 2 | 영영사전 정의 매칭 | `translation_blank` | passage에 정의문+지문 함께 넣고 num_answer_lines=1 |
| 3 | Word Box 단어 배열 영작 | `word_box` | |
| 4 | 표·요약 빈칸 채우기 | ⚠️ 수동 마무리 | 원본 표 구조가 셀 수가 많아 이번 버전 미지원. `translation_blank`로 지문+빈칸 텍스트만 넣고 표는 한글과오피스에서 직접 삽입 |
| 5 | 우리말 의미 영작(조건부) | `word_box` | |
| 6 | 어법 오류 찾고 고치기 | ⚠️ 수동 마무리 | 오류기호/고친표현 표 구조 미지원. `translation_blank`로 뼈대만 생성 후 표는 수동 삽입 |
| 7 | 학생 발화 중 틀린 내용 고르기 | `translation_blank` | passage에 학생 발화 전체를 넣고 답란에 이름+이유 작성 |
| 8 | 대명사 지칭 대상 | `translation_blank` | num_answer_lines를 지칭 대상 개수만큼(보통 1줄) |
| 9 | 함축 의미 우리말 서술 | `translation_blank` | |
| 10 | 조동사+have+p.p / 가정법 변형 | `translation_blank` | num_answer_lines=1 |
| 11 | 요지 영작 | `word_box` | |

**"⚠️ 수동 마무리" 유형**은 표(표·요약 빈칸, 오류기호/고친표현)가 필요한데, 원본의
표는 셀 구성이 복잡해(예: 7행×5열) 안전하게 자동 복제하기 어려워 이번 블록
라이브러리에서 제외했다. 이 유형이 꼭 필요하면 `translation_blank`로 지문과 발문까지
만들고, 표만 한글과오피스에서 직접 삽입하도록 사용자에게 안내한다.
