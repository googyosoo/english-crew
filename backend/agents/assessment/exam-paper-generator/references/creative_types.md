# 창의 유형 풀 (Creative Question Types)

수능 표준 유형을 벗어난 창의 유형. **객관식 18문항 중 1-2개**, **서술형 5문항 중 1개**까지만 사용. 적절한 지문이 없으면 사용하지 않는다.

---

## 객관식 창의 유형

### C-1. 글의 주장에 반대하는 근거로 적절하지 않은 것

(이미 표준 객관식 18에 포함됨 - 시험지1-2 17번 사례)

### C-2. 도움이 될 학생/상황 매칭

(이미 표준 객관식 17에 포함됨 - 시험지1-1 17번 사례)

### C-3. 본문 분석 발화 중 옳지 않은 것 (객관식판)

- **발문**: `다음 글에 대한 설명 중 옳지 않은 것만을 <보기>에서 있는 대로 고른 것은?`
- **형식**: 본문 + `<보기>` 안 ㄱ/ㄴ/ㄷ/ㄹ 4개 분석 진술 + 5지선다(조합)
- **분석 대상**: to-부정사 용법, 관계사 용법, 동격, 가정법, 수동/능동, 부사/형용사 구분
- **배점**: 4 ~ 4.5점 (상)
- **사례**: 시험지1-1 10번 (Auntie's place 본문에 대한 ⓐⓑⓒⓓ 분석)

### C-4. 본문 + 빈칸 + Word Box 결합 (혼합형)

- **발문**: `다음은 윗글을 요약한 ___이다. 빈칸에 알맞은 단어를 Word Box에서 찾아 그대로 완성하시오.` (단, 객관식 5지선다로 변형)
- **형식**: 본문 + 요약 표(빈칸 4개) + Word Box(8개) → 빈칸-단어 매칭 조합 5지선다
- **배점**: 4점 (상)

### C-5. 의미 사례 매칭 (밑줄 표현 → 일상 사례)

- **발문**: `밑줄 친 문장의 의미를 가장 잘 보여주는 상황으로 가장 적절한 것은?`
- **형식**: 본문 안 핵심 진술 + 5개 일상 사례 시나리오 (구체적 인물 행동 묘사)
- **배점**: 4 ~ 4.5점 (상)
- **사례**: 시험지1-1 18번 (act ourselves into a way of thinking → "He joined a club and began to value teamwork")

### C-6. 영영사전 정의 매칭 (객관식)

- **발문**: `밑줄 친 [어휘]는 다음 영영사전 뜻풀이 중 어느 의미로 쓰였는가?`
- **형식**: 본문 안 다의어 밑줄 + 영영 정의 5개 (각각 다른 의미) → 문맥에 맞는 1개 선택
- **배점**: 3.5점 (중)

### C-7. 글에 가장 어울리는 후속 문단

- **발문**: `다음 글 다음에 이어질 내용으로 가장 적절한 것은?`
- **형식**: 본문 마지막 문장 다음에 올 1단락 후보 5개 (영어 또는 한글)
- **배점**: 4점 (상)

## 서술형 창의 유형

### CD-1. 일기/감상문 빈칸 완성 (시험지1-1 서술형4(2) 사례)

- **발문**: `다음은 위 지문을 토대로 [인물]이 작성한 일기이다. 아래 빈칸을 주어진 <조건>에 따라 완성하시오.`
- **형식**: 본문(원사건) + 일기 형식 1인칭 회고문 + 마지막 한 문장 영작
- **<조 건>**: 단어 N개 사용 / 변형 가능 단어 명시 / 시작어 제시
- **배점**: 5점 (상)
- **사례**: New Zealand Kia ora mate → "I [recommend / companies / cautious / ... 단어로 영작]"

### CD-2. 본문 분석 발화 비판 + 이유 설명 (서술형판)

- **발문**: `(1) 학생 발화 중 틀린 친구 이름 모두 고르기 + (2) <보기>를 참고해 틀린 부분 설명하기`
- **형식**: 본문 + 학생 5-6명 발화 + `<보기>` 양식 모방하여 한국어로 이유 서술
- **배점**: 7점 (상)
- **사례**: 시험지1-1 서술형5, 시험지1-2 서술형1 (반복 빈출)

### CD-3. 본문 + 가정법/조동사 영작 결합 (시험지2-1 서술형1 사례)

- **발문**: `당신이 [본문 인물]이라면 [상황]에서 어떻게 했을지 <조건>에 맞게 영어로 쓰시오.`
- **<조 건>**: ① 10단어 이상 완전한 문장 ② 긍정/부정 답 선택 ③ 가정법 과거 사용 ④ 이유 포함
- **배점**: 6점 (상)
- **사례**: "If you were Nani Tama's grandson, would you drive him to Murupara?"

### CD-4. 영영 정의 + 본문 단어 + 의미 추론 결합

- **발문**: `(1) 본문에 사용된 의미에 따라 다음 단어의 뜻을 한글로 쓰시오. (2) 우리말 의미가 같도록 Word Box 단어를 배열하시오. (3) 어법상 틀린 단어 N개 찾아 고치시오.`
- **형식**: 다단계 결합형 (3-4개 소문항)
- **배점**: 8점 (상)
- **사례**: 시험지1-1 서술형4 (oversee/defense/acquisition/reverence + 단어 배열 + 어법 수정)

---

## 사용 원칙

1. **수능형 우선**: 표준 18+5에 없는 유형을 굳이 만들지 말 것. 위 창의 유형은 표준 풀에 이미 부분 포함.
2. **지문 적합성**: 지문이 창의 유형에 적합하지 않으면 사용 금지. (예: 짧은 안내문에 함축 의미 매칭 부적절)
3. **상한선 엄수**: 객관식 18문항 중 창의 유형은 **최대 2개**. 서술형 5문항 중 **최대 1개**.
4. **창의 유형 사용 시 정답·해설지에 표시**: `유형: 창의 (C-N)` 명기.
