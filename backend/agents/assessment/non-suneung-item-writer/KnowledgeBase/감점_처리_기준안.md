# 감점 처리 기준안 (Knowledge Base)

> 서술형/논술형 채점의 감점 규칙. 검수 단계에서 문항의 채점 가능성·공정성을 점검하고, 채점 시 일관 적용합니다.
> **갱신**: 학교 학업성적관리위원회 의결 기준으로 교체하세요.

## 1. 채점 대원칙
- 부분점수는 **사전 공개된 명시 기준**에만 부여.
- 동일 오류는 학생 전원에게 동일 감점(일관성).
- 정답의 다양성 인정 범위를 출제 시 미리 확정.

## 2. 감점 항목 (서술형 표준)
| 코드 | 오류 유형 | 감점 |
|---|---|---|
| G1 | 철자 오류(의미 저해 없음) | -0.5 |
| G2 | 어형/시제 오류 | -1 |
| G3 | 어순/구문 오류 | -1 |
| G4 | 조건 미준수(어휘 변형·단어수 등) | -1 ~ 전점 |
| G5 | 의미 전달 실패 | 전점 |
| G6 | 무응답/백지 | 0점 |

## 3. 정답 처리 규칙
- **복수정답 발생 시**: 출제 오류로 간주, 해당 선지 모두 정답 처리 → 검수 단계에서 사전 차단.
- **중의적 해석 여지**: 발문/선지 재작성 권고(검수 리포트에 명시).
- 채점 불가 문항은 전원 정답 또는 문항 무효(성적관리 가이드 따름).

## 4. 검수 연동
- 1·2단계 검수기는 각 문항이 위 G1~G6로 **명확히 채점 가능한지** 판정.
- 채점 모호 문항 → `중의성`/`복수정답` 플래그로 1단계 반려.
