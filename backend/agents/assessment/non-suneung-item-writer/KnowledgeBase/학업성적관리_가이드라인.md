# 국가수준 학업성적관리 가이드라인 (Knowledge Base)

> 지필·수행평가 운영의 상위 규준. 검수기가 어휘 범위·평가 타당도·문항 적법성을 판정할 때 참조합니다.
> **갱신**: 교육부/시도교육청 최신 학업성적관리 시행지침으로 검증·교체하세요. (반드시 학교 규정 확인)

## 1. 평가 일반 원칙
- 타당도·신뢰도·객관도·공정성을 갖춘 문항만 출제.
- 교육과정 성취기준에 근거한 출제(범위 외 출제 금지).
- 지필평가는 출제 → 동료 검토 → 결재의 절차를 거침(본 파이프라인의 2단계 검수가 1차 동료 검토 역할).

## 2. 출제 적법성 점검
- [ ] 성취기준 연계: 각 문항이 특정 성취기준 코드에 매핑되는가
- [ ] 어휘 범위: 교육과정/교과서 지정 어휘 내인가
- [ ] 난이도 분포: 변별을 위한 상·중·하 분포가 설계되었는가
- [ ] 정답 시비 소지: 복수정답·중의성 사전 제거되었는가

## 3. 수행평가 운영
- 과정중심 평가로 설계, 채점 기준(루브릭) 사전 공개.
- 결과는 누가 기록하여 피드백 제공(→ `Record_Studio/memory.md` 연동).
- 학생 데이터는 학교 개인정보 정책 준수, 외부 유출 금지.

## 4. 검수기 판정 우선순위
1) 적법성(범위·성취기준) → 2) 정답 무결성 → 3) 변별/난이도 → 4) 형식(배점·발문).
상위 위반이 있으면 하위 점검 결과와 무관하게 1단계 반려.
