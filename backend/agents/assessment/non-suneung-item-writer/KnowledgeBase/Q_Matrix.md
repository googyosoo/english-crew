# 수능형 다차원 문항 속성 매트릭스 (Q-Matrix)

> 확장 제안 구현. 오답 선지 구성 시 작동하는 **언어적 통제 메커니즘**을 매트릭스로 임베딩합니다. AI는 문항 생성 시 각 선지를 아래 속성으로 태깅하여 매력적이되 명확히 틀린 오답을 만듭니다.

## 1. 문항 속성 축 (Attributes)
| 축 | 속성 예시 |
|---|---|
| A. 인지 기능 | 사실 확인 / 추론 / 논리 관계 / 요지 종합 |
| B. 언어 단서 | 어휘 / 연결어 / 지시어 / 문장 구조 |
| C. 오개념 표적 | 부분 일치 / 반대 진술 / 범위 과대 / 무관 정보 |
| D. 난이도 | 상(추론+다단서) / 중 / 하(표면 단서) |

## 2. 정답·오답 설계 매트릭스
| 선지 | 정오 | A 인지 | C 오개념 표적 | 표면 단서 일치 |
|---|---|---|---|---|
| ① | 정답 | 추론 | — | 핵심 단서 일치 |
| ② | 오답 | 사실 | 부분 일치 | 본문 어휘 재등장(매력적) |
| ③ | 오답 | 추론 | 범위 과대 | 일반화 어구 |
| ④ | 오답 | 사실 | 반대 진술 | not/never 단서 |
| ⑤ | 오답 | 추론 | 무관 정보 | 그럴듯하나 본문 무근거 |

## 3. 오답 통제 규칙 (Distractor Control)
- 각 오답은 **표적 오개념 1개**만 담는다(복합 결함 금지 → 채점 모호 방지).
- 매력적 오답(②)은 본문 어휘를 재사용하되 논리적으로 틀리게 한다.
- 모든 오답은 "왜 틀렸는지" 1문장 근거를 검수 리포트에 첨부.
- 정답 단서는 본문에 **명시적**으로 존재해야 한다(내용 타당도).

## 4. 파이프라인 연동
- 1단계 생성기: 이 매트릭스로 선지를 태깅·생성.
- 2단계 검수기: 표적 오개념 중복/단서 부재/중의성을 탐지해 반려.
