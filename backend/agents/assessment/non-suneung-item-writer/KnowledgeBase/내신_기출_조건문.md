# 내신 기출 조건문 (Knowledge Base)

> 학교 내신 출제의 고정 조건·발문 어투를 코드화합니다. 2단계 검수 시 생성 문항을 이 문서와 대조합니다.
> **갱신**: 학교 실제 기출/출제 지침을 반영해 아래 항목을 교체하세요.

## 1. 발문 표준 어투 (Stem Conventions)
| 유형 | 표준 발문 |
|---|---|
| 주제 | 다음 글의 주제로 가장 적절한 것은? |
| 빈칸 | 다음 빈칸에 들어갈 말로 가장 적절한 것은? |
| 어법 | 다음 밑줄 친 부분 중 어법상 틀린 것은? |
| 순서 | 주어진 글 다음에 이어질 글의 순서로 가장 적절한 것은? |
| 삽입 | 글의 흐름으로 보아, 주어진 문장이 들어가기에 가장 적절한 곳은? |
| 서술형 | 본문의 내용과 일치하도록 빈칸을 완성하시오. (단, 주어진 어휘를 변형할 것) |

## 2. 출제 고정 조건 (Hard Constraints)
- 한 지문당 객관식 5지선다, 서술형은 부분점수 기준 명시.
- 서술형 답안은 단어수/형태 조건 명시(예: 3단어 이내, 어형 변화 허용).
- 본문 출처·저작권 표기 의무.
- 시험 범위 내 단원·어휘만 사용.

## 3. 출제 금지사항 (Prohibitions)
- 시중 문제집·EBS 원문항 동일 출제 금지(반드시 변형).
- 지엽적·함정성 문항 금지.
- 교과서 외 고난도 어휘를 정답 단서로 사용 금지.
- 정치·종교·특정 집단 비하 소재 금지.

## 4. 검수 매핑 키워드
검수기가 위반 탐지에 사용하는 키워드: `중의성`, `복수정답`, `어휘범위초과`, `발문불일치`, `배점오류`, `출처누락`.

## 5. Q-Matrix 선지 검증 표 서식 (Checklist Table)
모든 생성 문항에 대한 검수 리포트에는 문항 오류를 시각적으로 차단하기 위해 반드시 아래 **선지 분석 표**를 각 문항별로 첨부하여 출력해야 합니다.

| 선지 | 정오 | 인지 기능 속성 (A) | 오개념 표적 속성 (C) | 표면 단서 일치 여부 | 검수 결과 및 피드백 |
|---|---|---|---|---|---|
| ① | [정답/오답] | [인지 기능] | [표적 오개념 유형] | [일치/불일치] | [적합 또는 수정 권고 내용] |
| ② | | | | | |
| ③ | | | | | |
| ④ | | | | | |
| ⑤ | | | | | |

*   **판단 기준**: 각 오답 선지는 복합적인 결함이 아닌 **단 하나의 오개념(C)**만 명확히 저격해야 함.
*   **어휘 일관성**: 표면 단서(본문 어휘)가 정답과 오답 간에 골고루 분포되어 선지 모양새가 균질한지 체크함.
