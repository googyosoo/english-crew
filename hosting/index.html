2022 개정 교육과정 고교 영어과 지원

English Crew (잉글리시 크루)

고등학교 영어 교사를 위한 인공지능 기반 수업·평가 설계 및 분석적 루브릭 작성 조교 프로그램입니다.
교육부 고시 원문 성취기준을 100% 무결하게 인용하여 모호한 서술형 채점 기준표를 객관적 행동 지표로 자동 검증합니다.
교사의 최종 결재 승인을 거친 산출물만 공문 규격의 한글/워드(.docx) 파일로 안전하게 완성합니다.
정식 릴리스 버전: v1.0.0 (배포일: 2026-11-10)
설치형 프로그램 (권장)
시작 메뉴 및 바탕화면에 바로가기를 생성하고 편리하게 업데이트를 관리합니다.
EnglishCrew-Setup.exe 다운로드
포터블 프로그램 (무설치)
설치 과정 없이 USB나 원하는 폴더에서 즉시 단일 실행 파일로 시작합니다.
EnglishCrew-Portable.exe 다운로드

🚀 설치 및 시작 절차

  1. 위 다운로드 버튼 중 원하는 파일(설치형 또는 포터블)을 내려받습니다.
  2. 다운로드한 실행 파일(EnglishCrew-Setup.exe 또는 EnglishCrew-Portable.exe)을 더블 클릭합니다.
  3. Windows SmartScreen 알림 창이 나타나면 [추가 정보]를 누른 뒤 [실행] 버튼을 클릭합니다.
  4. 앱 화면 오른쪽 상단의 [API 설정] 메뉴에서 본인의 Google Gemini API 키를 등록합니다.
  5. 담당 과목(공통영어1, 공통영어2, 영어Ⅰ, 영어Ⅱ, 독해와 작문 등) 채널을 선택하고 수업·평가 설계를 요청합니다.
⚠️ Windows SmartScreen "Windows의 PC 보호" 안내:
공식 비영리 교육 오픈소스 배포 프로그램으로 고가의 유료 인증서 서명이 포함되지 않아 경고가 나타날 수 있습니다. 이는 정상적인 차단 창이며, [추가 정보]를 누른 뒤 [실행]을 클릭하시면 안전하게 기동됩니다.

🛡️ 학생 개인정보 보호 및 로컬 보안 체계

1. 학생 식별 데이터 및 API 키 완전 로컬 보관
교사가 입력한 학생 명단, 세특 기초 자료, 그리고 Gemini API 키는 교사의 컴퓨터 내부(userData 폴더)에만 격리 보관되며 개발자 서버나 외부 클라우드로 전송되지 않습니다.

2. Gemini 인공지능 통신 시 실명 가명화 전송
AI 분석을 위해 Google Gemini 서버로 전달되는 요청에는 학생 실명이 일절 포함되지 않고 Student 1, Student 2와 같은 무작위 식별자로 자동 가명화되어 전송됩니다.

💻 시스템 요구 사항

  • 운영체제: Microsoft Windows 10 또는 Windows 11 (64-bit 전용)
  • 네트워크: Google Gemini API 통신을 위한 유무선 인터넷 연결
  • 필수 계정/키: Google AI Studio에서 무료로 발급받을 수 있는 개인 Gemini API 키
