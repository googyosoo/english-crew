# English Crew (잉글리시 크루)

고등학교 영어 교사를 위한 2022 개정 교육과정 기반 AI 에이전트 협업 시스템입니다.

---

## 🌟 v1.1.0 신규 특화 기능 (현장 교사 고빈도 활용)

교사의 요청 성격에 맞추어 필요한 전문 지침만 선별 주입하는 **동적 스킬 로더** 엔진이 탑재되었습니다.

1. **수능형 영어 변형문제 제작 (`suneung-english-creator`)**
   - 수능 및 모의고사 출제 경향을 반영한 객관식 5지선다 빈칸추론 변형문항 출제
   - 오답 선지별 매력도 분석 및 Q-Matrix 정답 근거 표 자동 생성 (평가봇 연계)
2. **수준별 서술형 학술 문장 비계 (`edu-sentence-frame`)**
   - 상위, 중위, 하위 수준별 맞춤형 학술 문장틀(Sentence Frames) 및 담화 표제어 제공
   - 수행평가 에세이 작성 시 학습자의 인지 부하를 줄여주는 단계적 서술 가이드 설계 (수업봇 연계)
3. **3-Tier 어휘 수준 분류 및 지도 (`edu-vocab-tiering`)**
   - Beck과 McKeown 모형에 따른 기본어(Tier 1), 학술 빈출어(Tier 2), 전문소재어(Tier 3) 분석
   - 단원 핵심 어휘 카드 및 20분 맞춤형 어휘 지도 활동 자료 제작 (수업봇 및 교육과정봇 연계)

## 🚀 빠른 로컬 실행 방법 (Quick Start)

```bash
# 1. 의존성 설치
npm install
cd backend && python -m venv .venv && .venv\Scripts\pip install -r requirements.lock && cd ..

# 2. 로컬 개발 모드 구동 (Vite 프론트엔드 + Electron 데스크톱 앱)
npm run dev

# 3. 전체 회귀 테스트 스위트 검증 (35개 테스트 전원 통과)
backend\.venv\Scripts\python.exe -m pytest tests
```

## 1. 개요

English Crew는 총괄 코디네이터와 4인의 전문 에이전트(교육과정봇, 수업봇, 평가봇, 기록봇)가 협력하여 고등학교 영어 수업과 평가를 지원하는 데스크톱 애플리케이션입니다.
교사의 지시를 분석하여 과업을 분해하고, 전문 봇에게 체계적으로 배정하며, 교사의 최종 승인 절차를 거쳐 완성도 높은 수업 산출물을 생성합니다.

---

## 2. 4인 전문 에이전트 크루 구성

- **코디봇 (Coordinator)**: 교사 요청 해석, 과업 분해, 선행 관계 배정, 최종 산출물 취합 및 승인 결재 진행
- **교육과정봇 (Curriculum)**: 2022 개정 교육과정 공식 성취기준 매핑 및 평가요소 도출
- **수업봇 (Lesson)**: 차시별 교수학습 지도안 설계, 학생 맞춤형 활동지 제작
- **평가봇 (Assessment)**: 지문 없는 독립 작문형 논술 문항 출제 및 4수준 정량 루브릭 제작
- **기록봇 (Record)**: 학생 관찰 활동 기반 3단 구조(활동, 과정, 역량) 세특 문구 생성 (교육부 기재금지어 자동 필터링)

---

## 3. 설치 및 실행 환경

- **운영체제**: Windows 10 이상 (64비트)
- **런타임**: Python 3.10 이상, Node.js 18 이상 (소스 실행 시)
- **API 키**: Google Gemini API 키 (앱 설정 화면에서 등록, 로컬 기기에만 암호화 보관)
