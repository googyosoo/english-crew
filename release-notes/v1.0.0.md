# English Crew v1.0.0 릴리스 노트

고등학교 영어 교사를 위한 교육과정 기반 에이전트 크루 데스크톱 앱 정식 버전 v1.0.0 배포 안내입니다.

---

## 1. 주요 변경 사항 및 기능

### 2022 개정 교육과정 영어과 공식 과목 전면 지원
- 공통영어1, 공통영어2, 영어Ⅰ, 영어Ⅱ, 영어 독해와 작문, 심화 영어 독해와 작문, 미디어 영어 총 7개 교과 채널 및 전체 교무회의 채널 제공
- 교육부 고시 원문 성취기준(`kr-curriculum-2022/data/high/f08.jsonl`) 데이터베이스 기반 100% 무결 조회

### AI 에이전트 협업 및 검사 파이프라인
- **교육과정봇**: 교과별 공식 성취기준 및 단원 맥락에 최적화된 성취수준(A~E) 추출
- **평가봇**: 지문 없는 작문·토의형 문항 및 객관적 지표 중심의 4단계 분석적 채점기준표(루브릭) 출제
- **루브릭 검사기 (rubric_check)**: 모호한 정도 표현 배제, 수량 기준 일치, 경계 겹침 방지, 감점 표현 탐지 등 자동 검증 및 1회 자동 재생성
- **답안 검사기 (answer_check)**: 문항의 글자 수·문장 수 조건과 모범답안 충족 여부 상호 검증

### 교사 주도 결재 및 공문 규격 내보내기
- 산출물 검토 및 승인/반려(1회 한도 재작업) 결재 카드 시스템
- 학교 현장 양식에 부합하는 표 머리글 반복 및 서식 정리 워드 문서(.docx)와 마크다운(.md) 즉시 내보내기 지원

### 강력한 로컬 보안 아키텍처
- 32바이트 임의 보안 토큰 기반 내부 API 인증 (비인증 요청 차단)
- DNS 리바인딩 공격 차단 (TrustedHostMiddleware)
- Electron 45 최신 런타임 적용 및 완전 샌드박스(`sandbox: true`) 격리
- 인앱 외부 링크 이동 차단 및 기본 웹 브라우저 안전 연결 처리
- 학생 실명 식별자 가명화 전송(Student 1, Student 2) 및 로컬 PC 단독 보관

## 3. 설치 및 실행 안내
1. 원하는 형태의 실행 파일(`EnglishCrew-Setup.exe` 또는 `EnglishCrew-Portable.exe`)을 다운로드합니다.
2. Windows SmartScreen 창이 나타나면 **[추가 정보] → [실행]**을 순서대로 클릭합니다.
3. 최초 실행 시 표시되는 API 설정 대화상자에 본인의 Google Gemini API 키를 입력한 뒤 바로 수업 및 평가 설계를 시작할 수 있습니다.
