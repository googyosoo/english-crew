# English Crew v1.1.0 릴리스 노트

- 출시일: 2026년 11월 20일
- 버전: v1.1.0

---

## 주요 업데이트 내용

### 1. 동적 스킬 로더 탑재
- 교사의 요청 성격과 키워드를 분석하여 필요한 전문 스킬만 선별 주입하는 동적 로딩 엔진을 탑재했습니다.
- 프롬프트 토큰 낭비를 원천 방지하고, 각 에이전트가 본연의 과업과 결합된 고유 전문성을 발휘합니다.

### 2. 고빈도 3대 특화 기능 신규 지원
1. **수능형 영어 변형문제 제작 (`suneung-english-creator`)**
   - 수능 및 모의고사 출제 경향을 반영한 5지선다 빈칸추론 변형문항 생성
   - 정답 선택 근거 및 오답 선지별 매력도 분석표 제공
2. **수준별 서술형 학술 문장 비계 (`edu-sentence-frame`)**
   - 상위, 중위, 하위 수준별 학술 문장틀(Sentence Frames) 및 담화 표제어 제공
   - 수행평가 에세이 작성 시 학습자의 인지 부하를 줄여주는 단계적 서술 가이드 제공
3. **3-Tier 어휘 수준 분류 및 지도 (`edu-vocab-tiering`)**
   - Beck과 McKeown 모형에 따른 기본어(Tier 1), 학술 빈출어(Tier 2), 전문소재어(Tier 3) 분류
   - 단원 핵심 어휘 카드 및 맞춤형 어휘 지도 자료 설계

### 3. 검증 및 품질 무결성
- 7개 전용 회귀 테스트 스위트를 포함한 전체 35개 테스트 전원 통과 (100% PASS, 0 Failed)
- 실제 백엔드 및 Gemini API 연동을 거친 실전 산출물 생성 및 Electron 화면 캡처 검증 완료
