# English Crew 교사용 사용자 매뉴얼 (User Guide)

English Crew는 2022 개정 교육과정에 기반하여 고등학교 영어 교사의 수업 설계, 서술형·논술형 평가 문항 출제, 4수준 분석적 루브릭 작성을 지원하는 교사용 전용 데스크톱 프로그램입니다.

---

## 1. 시작하기 및 초기 설정

### 1-1. 프로그램 실행
- 바탕화면의 **English Crew** 아이콘을 더블 클릭하거나 시작 메뉴에서 검색하여 실행합니다.
- 프로그램이 켜지면 내부 보안 토큰이 자동 생성되며 로컬 백엔드 서버가 구동됩니다.

### 1-2. Google Gemini API 키 등록
1. 화면 오른쪽 상단의 **[API 설정]** 버튼을 클릭합니다.
2. [Google AI Studio](https://aistudio.google.com/)에서 발급받은 본인의 API 키를 입력합니다.
3. 사용할 모델(기본 권장: `gemini-2.5-flash`)을 선택한 뒤 **[저장]**을 누릅니다.
4. 등록된 키는 교사의 컴퓨터 로컬(`userData/.env`)에만 암호화 저장되며 외부 서버로 전송되지 않습니다.

## 2. 화면 구성

프로그램 화면은 크게 세 영역으로 나뉩니다:

```
┌─────────────────┬──────────────────────────────────┬─────────────────┐
│  과목 채널 목록   │        메시지 및 결재 피드         │   산출물 미리보기  │
│                 │                                  │                 │
│ • 공통영어1     │ [교사 요청 입력창]                │ • 최종 루브릭    │
│ • 공통영어2     │                                  │ • 평가 문항     │
│ • 영어Ⅰ        │ [코디봇·교육과정봇·평가봇 응답]    │ • 모범 답안     │
│ • 영어Ⅱ        │                                  │                 │
│ • 독해와 작문    │ [결재 카드: 승인 / 반려]          │ [Word 내보내기] │
│ • 심화 독해작문  │                                  │ [Markdown 복사] │
│ • 미디어 영어   │                                  │                 │
│ • 전체 교무회의 │                                  │                 │
└─────────────────┴──────────────────────────────────┴─────────────────┘
```

1. **왼쪽 (과목 채널 목록)**: 2022 개정 교육과정 기준 7개 교과 채널 및 전체 교무회의 채널이 준비되어 있습니다.
2. **중앙 (협업 피드)**: 교사의 지시문 입력, 봇들의 실시간 처리 과정, 검사기 결과, 결재 카드가 시간순으로 표시됩니다.
3. **오른쪽 (산출물 패널)**: 최종 생성된 서술형 문항과 루브릭 표를 실시간 확인하고 한글/워드(.docx) 문서로 내려받습니다.

## 3. 핵심 기능별 사용법

### 3-1. 수업 및 평가 문항 출제 요청

원하는 과목 채널(예: 영어Ⅰ)을 선택한 뒤 하단 입력창에 자연어로 요청합니다.

- **본문 미제공 모드 (지문 없는 일반 주제 작문/토의)**:
  > "본문 없이 일반 주제로 논술형 1문항과 4수준 루브릭 만들어줘"
  > "인공지능 윤리를 주제로 에세이 작성 수행평가 문항과 채점 기준표를 설계해줘"

- **본문 제공 모드 (특정 교과서 단원 기반 출제)**:
  > "3과 본문 내용을 바탕으로 중심 내용 요약 서술형 1문항과 루브릭을 작성해줘"
  > (지문 텍스트를 함께 붙여넣어 입력)

### 3-2. 다중 에이전트 자동 협업 파이프라인

교사가 요청을 전송하면 백그라운드에서 전문 봇들이 순차 협업합니다:
1. **코디네이터봇 (Coordinator)**: 요청을 분석하여 단원과 과제 유형을 판별하고 작업 계획을 수립합니다.
2. **교육과정봇 (Curriculum)**: 2022 개정 교육과정 공식 데이터베이스(`f08.jsonl`)에서 과목 성취기준 원문(예: `[12영Ⅰ01-01]`)과 성취수준(A~E)을 정확히 인용합니다.
3. **평가봇 (Assessment)**: 성취기준에 부합하는 서술형·논술형 문항과 4단계(A, B, C, D) 분석적 루브릭 표를 작성합니다.

### 3-3. 루브릭 및 답안 자동 무결성 검사

평가봇이 산출물을 작성하면 내장된 검사 엔진이 엄격한 기준을 자동 점검합니다:
- **객관적 수량 지표 검사**: '매우 잘함', '다소 미흡'과 같은 모호한 정도 표현이 단독으로 쓰이지 않았는지, '조건 3개 이상 충족'처럼 셀 수 있는 기준이 포함되었는지 확인합니다.
- **수준 간 경계 겹침 방지**: 인접 수준(B수준과 C수준 등)의 기준이 중복되지 않도록 방지합니다.
- **모범답안 조건 검사**: 문항에서 요구한 단어 수나 문장 수 조건이 모범답안과 일치하는지 대조합니다.
- 검사에서 결함이 발견되면 평가봇이 1회 자동 재생성을 거쳐 무결한 상태로 결재 카드에 올립니다.

### 3-4. 교사 결재 (승인 및 반려)

중앙 피드에 표시되는 결재 카드를 보고 교사가 최종 판단을 내립니다:
- **[승인] 클릭 시**:
  - 산출물이 최종 보관 폴더(`final/`)에 영구 저장됩니다.
  - 해당 차시 요약이 **차시기록**으로 컨텍스트에 자동 누적되어 다음 차시 설계에 반영됩니다.
  - 오른쪽 패널의 **[Word (.docx) 내보내기]** 버튼이 활성화되어 학교 공문 양식 표 서식이 적용된 워드 파일을 내려받을 수 있습니다.
- **[반려] 클릭 시**:
  - 팝업 창에 수정 요구 사항(예: "문항 배점을 10점으로 조정하고 필수 사용 어휘 3개 조건을 추가해줘")을 입력합니다.
  - 반려 사유를 반영하여 1회에 한해 새로운 재작업 파이프라인이 자동 시작됩니다.

## 4. 고급 기능 활용

### 4-1. 단원 맥락 메모 및 차시 기록 관리
- 오른쪽 상단 메뉴의 **[채널 맥락]**을 통해 이전 차시 진도, 교과서 단원 목표, 교사 메모를 기록할 수 있습니다.
- 누적된 차시 기록은 평가봇이 다음 문항을 출제할 때 이전 수업과의 연계성을 유지하는 바탕이 됩니다.

### 4-2. 정기 루틴 자동화 (Routine Scheduler)
- 주간 수업 준비나 정기 과제 점검을 자동화할 수 있습니다.
- 요일과 시간을 설정(예: 매주 월요일 오전 8시)해두면 지정된 채널에 수업 안내나 복습 퀴즈 초안을 자동으로 생성합니다.

## 5. 자주 묻는 질문 (FAQ)

**Q1. 학생 개인정보가 외부 AI 서버로 유출되지는 않나요?**
- 절대 유출되지 않습니다. 학생 명단과 세특 기초 자료는 교사의 PC에만 저장되며, Gemini API와 통신할 때는 `Student 1`, `Student 2` 등의 무작위 가명으로 자동 변환되어 전송됩니다.

**Q2. 교육과정 성취기준 코드가 실제 교육부 고시와 다를 수 있나요?**
- 없습니다. 시스템은 AI가 임의로 성취기준 코드를 지어내는 행위를 원천 차단하며, 2022 개정 교육과정 공식 원문 데이터베이스에서 검색된 코드와 진술문만 정확하게 복사하여 인용합니다.

**Q3. 한글(HWP) 파일로 내보낼 수 있나요?**
- 현재 정식 지원되는 형식은 Microsoft Word(`.docx`)와 마크다운(`.md`)입니다. 생성된 `.docx` 파일은 아래아한글 프로그램에서 바로 열람 및 편집이 가능합니다.
