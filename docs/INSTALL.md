# English Crew 설치 및 사용자 안내서

English Crew는 고등학교 영어 교과 수업 설계, 수능·학업성취도 문항 출제, 루브릭 작성, 학생 관찰 기록(세특)을 지원하는 5봇 협업 데스크톱 애플리케이션입니다.

---

## 1. 시스템 요구사항

- **운영체제**: Windows 10 이상 (64비트)
- **네트워크**: Google Gemini API 통신을 위한 인터넷 연결 필요
- **Google 계정**: Google AI Studio에서 발급받은 Gemini API 키

---

## 2. 설치 방법

### 방법 A: 설치 프로그램 실행 (권장)
1. 배포된 `English Crew Setup.exe` 또는 `English Crew Portable.exe`를 실행합니다.
2. 화면의 설치 마법사 안내에 따라 설치 경로를 지정하고 설치를 완료합니다.
3. 바탕화면 또는 시작 메뉴에 생성된 **English Crew** 아이콘을 클릭하여 앱을 실행합니다.

### 방법 B: 개발 환경에서 직접 실행
Node.js(v18+)와 Python(3.11+)이 설치된 환경에서는 터미널 명령으로 실행할 수 있습니다:
```bash
# 1. 의존성 설치
npm install
cd backend && python -m venv .venv && .venv\Scripts\pip install -r requirements.txt && cd ..

# 2. 실행
npm run dev
```

---

## 3. 첫 실행 및 API 키 등록

앱을 처음 실행하면 화면 중앙에 **Google Gemini API 키 설정** 창이 자동으로 나타납니다.

1. 웹 브라우저에서 [Google AI Studio](https://aistudio.google.com/)에 접속하여 무료 API 키를 발급받습니다.
2. 앱의 입력창에 발급받은 API 키(`AIzaSy...`)를 붙여넣습니다.
3. **[API 키 저장 및 활성화]** 단추를 누릅니다.
4. 왼쪽 아래 상태바가 녹색 점과 함께 `연결됨 · Gemini · gemini-2.5-flash`로 바뀌면 정상적으로 준비가 완료된 것입니다.

> **개인정보 및 보안 안내**:
> - 교사가 입력한 API 키는 사용자 컴퓨터 로컬(`%APPDATA%\english-crew\.env`)에만 안전하게 보관됩니다.
> - 학생의 실명은 외부 AI로 전송되지 않으며, 로컬에서 학번 토큰(예: `[S03-01]`)으로 자동 치환된 후 처리됩니다.

## 4. 첫 수업·평가 요청 및 결재 진행

### 단계 1: 과목 채널 선택
왼쪽 사이드바에서 작업을 진행할 과목 채널(예: **영어Ⅰ**)을 선택합니다.

### 단계 2: 교과서 본문 등록 (선택 사항)
1. 오른쪽 패널의 **[수업 맥락]** 탭을 클릭합니다.
2. 단원(예: 3과)을 선택한 뒤 교과서 본문 텍스트를 붙여넣고 **[본문 저장]**을 누릅니다.
   - 본문 없이 독립 작문 과제를 만들고자 할 때는 요청 시 "본문 없이" 또는 "일반 주제로"라고 입력하면 본문 없이 곧바로 출제됩니다.

### 단계 3: 교사 요청 입력
채팅창에 원하는 작업을 구체적으로 입력하고 전송합니다:
```text
본문 없이 일반 주제로 논술형 1문항과 4수준 루브릭 만들어줘
```

### 단계 4: 코디봇 총괄 및 팀원봇 협업
1. **코디봇**이 요청을 분석하여 교육과정봇, 평가봇에 과업을 배정합니다.
2. **교육과정봇**이 2022 개정 교육과정 성취기준을 엄밀하게 확인합니다.
3. **평가봇**이 조건에 부합하는 서술형 문항, 모범답안, 정량적 루브릭을 제작합니다.
4. 백엔드 검사 엔진이 성취기준 코드 일치 여부, 정량 지표 포함 여부, 모범답안 길이 조건을 자동으로 검증합니다.

### 단계 5: 산출물 확인 및 결재 승인
1. 작업 보고 카드의 산출물 항목을 클릭하면 오른쪽 **[산출물]** 패널에서 마크다운 전문을 미리 볼 수 있습니다.
2. 내용이 만족스러우면 결재 카드의 **[승인]** 단추를 누릅니다.
3. 승인된 산출물은 즉시 `data/workspaces/{과목}/{단원}/final/` 폴더로 안전하게 보관되며, 오른쪽 **[내보내기 ▾]** 메뉴를 통해 Word(`.docx`) 또는 Markdown(`.md`) 파일로 내려받을 수 있습니다.

## 5. 정기 자동화 루틴 활용

매주 반복되는 수업 준비(어휘 퀴즈, 활동지 초안 제작 등)는 오른쪽 패널의 **[루틴]** 탭에서 스케줄을 등록해 둘 수 있습니다.

1. **[루틴 추가]** 단추를 눌러 루틴 이름, 대상 채널, 요일, 시각, 요청 문장을 입력합니다.
2. 앱이 켜져 있는 동안 지정된 시각에 자동으로 요청이 발송되며, 결과는 결재 대기 상태로 등록되어 교사의 최종 확인을 기다립니다.
3. 지정 시각에 앱이 꺼져 있었다면, 다음에 앱을 켤 때 놓친 루틴이 1회 자동으로 보충 실행됩니다.

## 6. 문제 해결 (FAQ)

- **상태바에 '오프라인'이 표시되는 경우**: 백엔드 프로세스가 정상 기동되지 않았을 수 있습니다. 앱을 완전히 종료한 뒤 다시 실행해 주십시오.
- **API 키를 다시 변경하고 싶은 경우**: 왼쪽 아래 상태바를 클릭하면 언제든지 API 키 입력 창이 다시 열립니다.
- **내보내기 폴더를 변경하고 싶은 경우**: 오른쪽 패널 오른쪽 위의 톱니바퀴(⚙️) 아이콘을 눌러 원하는 폴더(예: Google Drive 동기화 폴더)로 지정할 수 있습니다.
