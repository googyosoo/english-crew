# Activities — Comprehension Check (이해 확인 활동)

본문의 어휘·문법·내용 이해를 점검하는 활동 모음. 대부분 개인 활동이지만 짝 점검 단계를 붙일 수 있다.

각 활동은 다음 항목을 갖춘다: **목표 / 형태·시간 / 절차 / 학생용 자료 형식 / 학생용 자료 요소 / 교사용 가이드 요소 / 변형 / 본문 후크 활용**

---

## 1. Cloze Test (선택적 빈칸 채우기)

- **목표**: 어휘·연어·구문 인지력 점검
- **형태/시간**: 개인 / 10-15분
- **절차**: ①본문에서 핵심어 12-15개 빈칸 처리(첫 문장은 단서로 남김) → ②학생 빈칸 채우기 → ③짝 점검 → ④교사 함께 정답 확인
- **학생용 자료 형식**: 워크시트 (worksheet)
- **학생용 자료 요소**:
  - 빈칸 처리된 본문 (밑줄 + 번호)
  - Word Bank (정답 + 함정 단어 2-3개 섞어 약 18개)
  - 짝 점검 칸 (Pair Check)
- **교사용 가이드 요소**: 정답표 / 자주 틀리는 빈칸 분석 / 변형 (Word Bank 없는 challenging 버전)
- **변형**: 첫 글자 단서, 동의어 단서, 그림 단서
- **본문 후크 활용**: 빈칸으로 뽑을 단어는 "주제어 / 시제 표지 / 연결어" 우선

---

## 2. T/F + Justify (참·거짓 + 근거)

- **목표**: 사실 이해 + 본문 근거 인용 능력
- **형태/시간**: 개인 → 짝 / 15-20분
- **절차**: ①교사 8-10개 진술 제시 → ②학생 T/F 표시 + 근거 문장 본문에서 인용 → ③짝과 비교 → ④교사와 함께 확인
- **학생용 자료 형식**: 워크시트
- **학생용 자료 요소**:
  - 진술 8-10개 (T 4-5, F 4-5, 본문에서 직접 vs 추론 vs 부분왜곡 섞음)
  - 각 진술에 T/F 동그라미 + "Evidence (line ___)" 적는 칸
  - 짝 비교 결과 적는 칸
- **교사용 가이드 요소**: 정답 / 각 진술의 출제 의도 (직접 / 추론 / 함정) / 학생 답변 채점 시 "근거 인용" 비중을 더 크게 두라는 안내
- **변형**: T/F/NG (Not Given) 3택, 그룹별 T 진술만 만들고 교환

---

## 3. 5W1H Reading Map

- **목표**: 정보 추출 구조화 / 내러티브·기사문 핵심 정보 인지
- **형태/시간**: 개인 / 15분
- **절차**: ①본문 1독 → ②5W1H 격자에 정보 채우기 → ③짝과 비교·보완 → ④교사 확인
- **학생용 자료 형식**: 그래픽조직자 (organizer)
- **학생용 자료 요소**: 6칸 격자(Who/What/When/Where/Why/How), 각 칸에 단어·구·문장 모두 허용 표시, 하단 "One-Sentence Summary" 칸
- **교사용 가이드 요소**: 모범 답 / Why·How는 추론 요소가 들어갈 수 있음을 안내 / 영어로 못 쓰는 학생을 위해 한글 첫 작성 → 영어 변환 단계 옵션
- **변형**: 인물별 5W1H (다중 인물 본문), 시간 순 사건 5W1H (순차 본문)
- **본문 후크 활용**: 내러티브·기사문에 가장 강함

---

## 4. Reading Q&A 3단 (단계별 질문)

- **목표**: 표층 이해 → 추론 → 비판적 사고로 단계 이동
- **형태/시간**: 개인 / 20-25분
- **절차**: 3단 질문지 풀이. 단계마다 짝 점검 가능
- **학생용 자료 형식**: 워크시트
- **학생용 자료 요소** (질문 9개, 단계당 3개):
  - 1단계 Literal (사실 확인): "What did X do?", "When did Y happen?"
  - 2단계 Inference (추론): "Why might X have felt ___?", "What does ___ imply?"
  - 3단계 Critical (비판/적용): "Do you agree with X's decision? Why?", "How would you respond if ___?"
  - 각 질문에 답안 작성 칸 (1단계 1줄, 2단계 2줄, 3단계 3-4줄)
- **교사용 가이드 요소**: 단계별 모범답안 / 채점 비중 (1단계 일치, 2단계 합리성, 3단계 본문 근거+논리) / 3단계는 다양한 답 허용
- **변형**: 단계별 점수 배분(20/30/50), 모둠별 1단계씩 책임 후 발표
- **본문 후크 활용**: 모든 장르에 적용 가능. 논설문에서 특히 강함

---

## 5. Vocabulary Log (어휘 기록·심화)

- **목표**: 핵심 어휘 5-8개를 깊이 학습 (의미·예문·연어·동의어)
- **형태/시간**: 개인 / 15-20분
- **절차**: ①교사가 본문에서 핵심 어휘 5-8개 지정 → ②학생이 표 채우기 → ③짝 교환 점검 → ④Quizlet 등록 안내(선택)
- **학생용 자료 형식**: 워크시트 (표)
- **학생용 자료 요소**: 어휘별로 [Word / Part of speech / Meaning in Korean / Meaning in English / Original sentence (in text) / My own sentence / Synonym or related word]
- **교사용 가이드 요소**: 어휘 선택 기준 (CEFR B1 이상 + 본문 핵심어 + 다른 차시·교과서에 재출현 가능성) / 모범 예시 / Quizlet set 만들기 안내
- **변형**: 어휘 카드(앞=영, 뒤=한+예문) 만들어 Quiz Quiz Trade 활동으로 연계
- **본문 후크 활용**: "내 문장 만들기" 칸은 본문 주제와 연결되도록 유도 (e.g., "이 단어로 본문 인물의 행동 묘사하기")

---

## 6. Order the Events (사건 순서 배열)

- **목표**: 시간·논리 순서 파악
- **형태/시간**: 개인 → 짝 / 10-15분
- **절차**: ①섞인 6-8개 사건 카드 → ②순서 배열 → ③짝과 비교 → ④본문 다시 보고 확정
- **학생용 자료 형식**: 워크시트 + 잘라 쓰는 카드 (선택)
- **학생용 자료 요소**: 섞인 영어 사건 진술 6-8개 (각 진술 옆에 ☐ 번호 칸), 또는 잘라 쓰는 카드 그리드
- **교사용 가이드 요소**: 정답 순서 / 헷갈리는 페어 (인접 사건이 모호한 경우 분석) / 시간 표지 단서 (then, after, finally 등)
- **변형**: 인과 순서 배열(원인→결과), 논설문의 논리 단계 배열 (claim → evidence → conclusion)
- **본문 후크 활용**: 내러티브·기사문·실험 보고문에 강함

---

## 7. Grammar Hunt (목표 문법 사냥)

- **목표**: 본문에 등장하는 목표 문법 인지 + 변형 연습
- **형태/시간**: 개인 → 짝 / 15-20분
- **절차**: ①교사가 목표 문법 1-2개 명시 (e.g., 가정법 과거, to부정사 의미상 주어) → ②학생이 본문에서 해당 문법이 사용된 모든 문장을 찾아 형광펜 → ③한 문장 골라 의미 한국어 번역 → ④한 문장은 다른 형태로 변형 (e.g., 가정법 과거 → 직설법) → ⑤짝과 비교
- **학생용 자료 형식**: 워크시트
- **학생용 자료 요소**: 목표 문법 안내 박스 + 본문 발췌(밑줄 칠 자리 충분) + "찾은 문장 옮겨 적기" 칸 + "변형 연습" 칸
- **교사용 가이드 요소**: 목표 문법별 본문 출현 위치 / 변형 모범 예 / 자주 나오는 오류
- **변형**: 모둠별로 다른 문법 분담 후 발표(jigsaw 변형)
- **본문 후크 활용**: 본문이 특정 문법 자질을 풍부하게 담을 때만 강함. 표 1의 "어법 풍부도" 확인 후 추천

---

## 카테고리 공통 가이드

- **점검 단계 끼우기**: 거의 모든 활동에 "짝 점검(Pair Check)" 또는 "교사 확인(Teacher Check)" 단계를 1-2분 추가하면 정착도가 올라간다.
- **답 작성란 분량**: 1줄 답에는 한 줄, 2줄 답에는 두 줄, 자유 응답에는 4-5줄. 너무 좁으면 학생이 답을 압축하고, 너무 넓으면 빈약함이 두드러진다.
- **영어 발화 부담 줄이기**: 기초 학생 학급에서는 답안 작성을 영어/한국어 병기 허용으로 표시한다 ("Answer in English or Korean").
