# Activities — Production (산출 활동)

학생이 영어로 표현(말하기·쓰기)을 만들어 내는 활동. 본문 내용을 변형·확장·재구성하여 자기 언어로 옮긴다.

각 활동: **목표 / 형태·시간 / 절차 / 학생용 자료 형식 / 학생용 자료 요소 / 교사용 가이드 요소 / 변형 / 본문 후크 활용**

---

## 1. 3-Sentence Summary (3문장 요약)

- **목표**: 핵심 정보 압축, 문장 단위 영어 산출
- **형태/시간**: 개인 → 짝 비교 / 15분
- **절차**: ①본문 1독 → ②"누가/무엇이 / 무엇을 했고 / 그래서 어땠다" 3문장으로 요약 → ③짝과 교환 / 다른 점 표시 → ④교사 모범 요약 제시
- **학생용 자료 형식**: 워크시트
- **학생용 자료 요소**:
  - 안내: "Write exactly 3 sentences. Each ≤ 15 words."
  - 3개 줄 (S1, S2, S3) + 단어 수 카운터 칸
  - 짝 비교 박스: "What did you keep? What did you cut? What did your partner add?"
- **교사용 가이드 요소**: 모범 요약 2-3개 / 채점 포인트 (사건 인과·인물·결말 모두 포함되었는지) / 학생이 흔히 빠뜨리는 핵심
- **변형**: 1-Sentence Summary (도전), 5-Sentence Summary (보통), Headline + 3 Sentences (기사문)
- **본문 후크 활용**: 모든 장르 적용. 내러티브·기사문에 가장 강함

---

## 2. Opinion Paragraph (의견 문단)

- **목표**: 본문 주제에 대한 자기 의견을 단락으로 산출
- **형태/시간**: 개인 / 20-25분
- **절차**: ①본문 핵심 주장·이슈 확인 → ②찬/반/조건부 입장 결정 → ③Topic Sentence + Reason 1 + Reason 2 + Concluding Sentence 단락 작성 → ④짝/모둠 공유
- **학생용 자료 형식**: 워크시트
- **학생용 자료 요소**:
  - Issue 명료화 박스 (한 문장으로 본문 이슈 적기)
  - 입장 체크: ☐ Agree ☐ Disagree ☐ It depends
  - 단락 구조 가이드 (4-5 문장 슬롯)
  - Useful expressions 박스 (In my opinion / However / For example / Therefore 등 8-10개)
  - Self-check: 본문 근거 1개 이상 인용했는지 ☐
- **교사용 가이드 요소**: 모범 단락 1개 + 흔한 오류 (주장만 있고 근거 없음, 본문과 무관한 일반론) / 평가 루브릭 (내용·구조·언어 각 5점)
- **변형**: 짝과 입장 다른 사람 매칭 후 미니 토론 1분 → 다시 단락 보강
- **본문 후크 활용**: 논설문·체험기에 강함. 내러티브일 때는 "인물의 결정에 동의하는가?"로 변환

---

## 3. Retell Relay (이어 말하기)

- **목표**: 본문 내용을 자기 말로 재구성 (말하기)
- **형태/시간**: 짝 또는 4인 모둠 / 15-20분
- **절차**: ①사건/단락을 인원수만큼 분할 → ②각자 자기 부분 1분 정리 → ③순서대로 이어 말하기 → ④듣는 사람은 "한 문장 요약" 메모 → ⑤전체 흐름 다시 짚기
- **학생용 자료 형식**: 워크시트 (메모용) + 짝 활동 안내 카드
- **학생용 자료 요소**:
  - 본인 담당 부분 표시 칸
  - Speaking Notes 칸 (단어·구 메모. 문장 통째로는 금지 — 보고 읽지 말기)
  - Listener's One-Sentence Summary 칸 × 3 (다른 친구 발화 듣고 적기)
  - Useful sentence starters (First / Then / After that / Meanwhile / Finally)
- **교사용 가이드 요소**: 모둠 구성 안내 / 영어 발화 부담 학생 대처 (Speaking Notes에 한글 단어 1-2개 허용) / 말하기 시간 30초-1분 권장 / 평가 관찰 포인트 (전달성 / 정확성 / 협력성)
- **변형**: 인물별 시점 Retell (각자 다른 인물 입장), 한 명 말할 때 다른 사람들이 추가 질문 1개씩
- **본문 후크 활용**: 내러티브·실험·보고문 (시간/논리 분할 가능 본문) 강함

---

## 4. Letter to Character (인물에게 편지)

- **목표**: 본문 인물에게 영어 편지 형식으로 의견·질문·조언 전달
- **형태/시간**: 개인 / 20-25분
- **절차**: ①본문 인물 1명 선택 → ②인물에게 묻고 싶은 것·말하고 싶은 것 정리 → ③편지 형식으로 작성 (Dear ___ / 본문 / Sincerely, ___)
- **학생용 자료 형식**: 워크시트 (편지지 형태)
- **학생용 자료 요소**:
  - Dear ___ , 칸
  - 본문 5-7줄 편지지 (가로줄 인쇄)
  - Useful expressions: "I read about you in...", "I was surprised when...", "If I were you, I would...", "Could you tell me more about...?"
  - Sincerely / Best regards, ___ 칸
- **교사용 가이드 요소**: 편지의 3요소 (감상·질문·조언) 가이드 / 모범 예시 1개 / 인물 답장 받기 (다음 차시 짝과 답장 교환) 변형 안내
- **변형**: 두 인물 사이 가상 편지 / 편지 → 답장 (짝 활동 연계)
- **본문 후크 활용**: 내러티브·전기·체험기에 강함

---

## 5. Continue the Story (이야기 이어 쓰기)

- **목표**: 창의적 영어 산출, 본문 어휘·구문 재사용
- **형태/시간**: 개인 / 25-30분 (또는 차시 후 과제)
- **절차**: ①본문 마지막 장면 다시 읽기 → ②"What happens next?" 브레인스토밍 → ③5-8문장 분량 다음 장면 작성 → ④짝과 교환 / 모둠 베스트 1편 발표
- **학생용 자료 형식**: 워크시트
- **학생용 자료 요소**:
  - 본문 마지막 단락 발췌 (이어 쓰기 시작점 확인)
  - Brainstorm 칸 (Setting / New event / Character's reaction / Ending — 4칸)
  - 본문 5-8문장 작성 칸 (가로줄)
  - "Use at least 3 words from the original text" 체크박스
- **교사용 가이드 요소**: 우수작 평가 기준 (어휘 재사용 / 구문 정확성 / 일관성 / 창의성) / 학급 공유·낭독 옵션
- **변형**: 다른 결말 쓰기 / 등장 인물 한 명 추가 / 시점 바꿔 쓰기
- **본문 후크 활용**: 내러티브·열린 결말 본문에 강함. 결말이 닫혀 있으면 "10년 후" 시나리오로 변환

---

## 6. News Report (뉴스 기사 변환)

- **목표**: 본문 내용을 신문 기사 양식으로 재구성
- **형태/시간**: 개인 또는 짝 / 25-30분
- **절차**: ①본문에서 사건/사실 추출 → ②Headline / Lead (5W1H 한 문장) / Body / Quote 단계로 작성 → ③모둠 공유 / 게시
- **학생용 자료 형식**: 워크시트 (신문 레이아웃)
- **학생용 자료 요소**:
  - Headline 칸 (대문자 굵게 안내)
  - Lead Sentence 칸 (5W1H 한 문장)
  - Body 칸 (3-4문장)
  - Quote 칸 ("____," said ____.)
  - Reporter Name 칸
- **교사용 가이드 요소**: Headline 작성 팁 (현재형 시제, 짧고 강하게) / 모범 기사 1개 / 게시판 활용 안내
- **변형**: 인터뷰 기사 형식 (Q&A) / 사설 기사 형식 (의견 강조)
- **본문 후크 활용**: 사건·발견·이벤트가 있는 본문에 강함 (실험·뉴스·역사 일화)

---

## 7. Tweet Translation (140자 변환)

- **목표**: 핵심 메시지를 짧게 압축 + 현대적 어조로 변환
- **형태/시간**: 개인 → 모둠 공유 / 10-15분
- **절차**: ①본문 인물/저자가 트위터를 했다면? 가정 → ②본문 1독 후 핵심 메시지·느낌 추출 → ③140자(또는 280자) 영어로 작성 → ④해시태그 2-3개 추가 → ⑤모둠 안에서 공유 / Best Tweet 투표
- **학생용 자료 형식**: 워크시트 (트윗 카드 박스)
- **학생용 자료 요소**:
  - 트윗 박스 (140 char 카운터 표시)
  - Hashtags 칸 (#___ #___ #___)
  - "Whose voice are you tweeting from?" 인물 명시 칸
  - Likes·Replies 가상 칸 (모둠 친구가 적어 주는 한 줄 반응)
- **교사용 가이드 요소**: 압축의 의미 (핵심 vs 디테일) / SNS 영어 표현 안내 (lol, btw 같은 인포멀 어휘는 학습 맥락에 맞게 허용 여부 결정) / 모범 트윗 1개
- **변형**: Instagram caption + 가상 사진 묘사 / Reply chain (모둠이 답글 1개씩)
- **본문 후크 활용**: 모든 장르 적용. 짧은 본문에 특히 좋음

---

## 카테고리 공통 가이드

- **모범 예시 항상 제공**: 산출 활동에서 학생들이 가장 막히는 것은 "어떻게 시작하지?" 단계. 교사용 가이드에 모범 예시 1개를 반드시 넣고, 활동지에는 sentence starter 박스를 둔다.
- **시간 안내 명시**: "20분 안에 ___ 정도 분량"이 워크시트에 보여야 학생들이 페이스를 맞춘다.
- **평가 ≠ 채점**: 산출물에 점수를 매기지 않더라도 "관찰 포인트"를 교사 가이드에 둬서 다음 차시 피드백·세특 자료로 활용한다.
- **글쓰기 평가 연계**: 정식 평가가 필요하면 별도로 `writing-critic` 스킬을 사용하라고 안내한다.
