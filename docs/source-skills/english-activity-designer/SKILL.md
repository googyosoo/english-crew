# English Activity Designer (영어 본문 활동 설계기)

고등학교 영어 교과서 읽기 본문 1개에서 학습 활동을 설계·제작하는 스킬. **추천(5개) → 선택(1개) → 제작(학생용+교사용 docx)** 의 3단계 워크플로.

## 핵심 사양

| 항목 | 값 |
|---|---|
| 입력 | 영어 본문 (txt/pdf/docx/md/인라인) 1개 |
| 추천 활동 수 | 5개 (4개 카테고리 분산) |
| 출력 | `학생용_활동지.docx` + `교사용_가이드.docx` (별도 2개) |
| 출력 언어 | 학생용은 영어 위주(지시문은 한국어 병기), 교사용은 한국어 |
| 활동 카테고리 | ① 이해 확인 ② 산출 활동 ③ 협력·게임 ④ 프로젝트·심화 |
| 학생용 형식 | 활동 유형에 따라 자동 선택: 워크시트 / 카드세트 / 그래픽조직자 / 슬라이드형 |
| 시간 단위 | 차시(45-50분) 기준. 부분 활동은 분 단위 표기 |

## 워크플로 (반드시 순서대로)

### Step 1. 입력 수집
사용자에게 다음을 확인한다 (이미 제공된 정보는 건너뜀):

1. **본문**: 텍스트 또는 파일. PDF/DOCX는 `pdf-reading` / `docx` 스킬로 먼저 텍스트 추출.
2. **선택 정보**(있으면 추천 정확도 ↑, 없으면 기본값 사용):
   - 학년: 기본 고1
   - 차시 위치: 도입 / 전개 / 정리 / 차시 후 (기본 "전개")
   - 학생 수준: 기초 / 중급 / 심화 (기본 "중급")
   - 사용 가능 시간: 기본 25분 (1차시 중 활동 비중)
   - 선호 카테고리: 사용자가 특정하면 가중치 부여 (안 하면 4개 균형)

### Step 2. 본문 분석
다음 6개 축으로 본문을 태깅한다 (내부 분석, 사용자에게는 요약만 보여줌):

| 축 | 값 |
|---|---|
| 길이 | 단어 수 (짧음 ≤150 / 보통 150-300 / 김 >300) |
| 장르 | 내러티브 / 설명문 / 논설문 / 대화문 / 안내문 / 인터뷰 등 |
| 주제 | 1-2개 키워드 |
| 어휘 난도 | 기초 / 중급 / 심화 (CEFR 추정 A2-B2) |
| 핵심 언어 자질 | 시제·구문·연결어·수사법 중 두드러진 1-2개 |
| 정의적 요소 | 인물·갈등·논쟁점·체험 가능성 (활동 후크 발굴용) |

이 분석은 `references/selection_criteria.md` 의 매칭 표와 결합되어 추천에 사용된다.

### Step 3. 활동 추천 (5개)
**반드시** `references/selection_criteria.md` 를 읽고, 본문 태깅 결과를 매칭표에 통과시켜 5개 활동을 선정한다.

선정 규칙:
- **카테고리 균형**: 4개 카테고리 모두 최소 1개 등장 (1+1+1+1 + 자유 1)
- **사회적 형태 다양성**: 개인 / 짝 / 모둠 중 최소 2개 형태가 포함되도록
- **시간 적합성**: 사용 가능 시간 ±10분 이내인 활동만 추천
- **본문 적합성**: 매칭표 적합도 "상" 우선, "중"까지만 허용 (하 제외)
- **사용자 선호**: 선호 카테고리가 있으면 그 카테고리 활동을 2개까지 허용

추천을 다음 표 형식으로 제시한다:

```
| # | 활동명 | 카테고리 | 형태 | 시간 | 한 줄 설명 | 적합도 근거 |
|---|---|---|---|---|---|---|
| 1 | Hot Seat | 협력·게임 | 모둠 | 20분 | 본문 인물에게 모둠이 질문 | 내러티브+인물 갈등 명확 |
...
```

표 아래에 "어떤 번호로 진행할까요?"로 닫는다. **여기서 일단 출력을 멈추고** 사용자의 선택을 기다린다. 자동으로 1번을 고르거나 여러 개 만들지 않는다.

### Step 4. 활동 자료 제작
사용자가 번호를 고르면 해당 활동의 상세 명세를 카테고리별 reference에서 찾아 자료를 만든다.

활동별 상세 명세는 다음에서 찾는다 (활동 카테고리에 맞는 파일 1개만 읽으면 됨):
- `references/activities_comprehension.md` (이해 확인)
- `references/activities_production.md` (산출 활동)
- `references/activities_cooperative.md` (협력·게임)
- `references/activities_project.md` (프로젝트·심화)

각 reference 파일에는 활동별로 다음이 들어 있다:
- 활동 정의·교육적 효과
- 진행 절차 (분 단위)
- 학생용 자료 형식 (worksheet / card_set / organizer / slide 중 하나)
- 학생용 자료 필수 요소
- 교사용 가이드 필수 요소
- 변형(variation) 옵션

학생용 자료의 docx 구성은 `references/output_formats.md` 의 형식별 템플릿을 따른다.

### Step 5. 자가검증 (출력 전)
다음 체크리스트를 통과해야 한다. 실패 시 수정:

- [ ] 학생용 자료가 본문 없이도 작동하는가? (본문 인용/발췌가 적절히 포함)
- [ ] 지시문이 학생 수준에 맞는 영어인가? (필요 시 한국어 병기)
- [ ] 모든 빈칸·표·박스에 답을 쓸 충분한 공간이 있는가?
- [ ] 짝/모둠 활동의 경우 역할(A/B 또는 1/2/3/4)이 명확히 구분되는가?
- [ ] 카드세트의 경우 잘라 쓰기 좋게 구획선이 표시되는가? (점선 또는 표 경계)
- [ ] 교사용 가이드에 시간 배분, 진행 순서, 예상 어려움·대처법, 평가 포인트가 모두 있는가?
- [ ] 본문에 없는 정보를 학생이 만들어 내야 하는 활동이라면 사전 지식 점화/예시가 충분한가?

### Step 6. docx 생성 및 출력
**반드시** `/mnt/skills/public/docx/SKILL.md` 를 먼저 읽는다. 그 가이드에 따라 두 파일을 생성한다.

1. **학생용 활동지** (`{본문제목 또는 활동명}_학생용.docx`)
   - 헤더: 활동명(영문) / 한국어 부제 / Class·Number·Name 기입란
   - 본문 발췌(필요한 경우만, 짧게)
   - 활동 형식에 맞는 본체: `references/output_formats.md` 의 해당 섹션 참조
   - 푸터: 활동 시간 안내 / 평가 방식 한 줄

2. **교사용 진행 가이드** (`{본문제목 또는 활동명}_교사용.docx`)
   - 활동 개요: 학습목표·소요시간·필요물품·사회적 형태
   - 진행 단계: 도입(○분) → 전개(○분) → 정리(○분), 각 단계 교사 발화·행동 예시
   - 학생 활동지 모범답안/예시답안
   - 예상 어려움 + 대처 카드 (학생이 영어로 못 말할 때, 모둠 갈등, 시간 초과 등)
   - 평가/관찰 포인트: 무엇을 보고 무엇으로 기록할지 (세특 연계 가능 시 항목 명시)
   - 변형 옵션 1-2개

생성 후 `/mnt/user-data/outputs/` 로 복사하고 `present_files` 로 두 파일을 함께 제시한다.

## 활동 풀 개요 (상세는 references)

| 카테고리 | 활동 (대표) | 적합 본문 | 형식 |
|---|---|---|---|
| ① 이해 확인 | Cloze, T/F+Justify, 5W1H Map, Reading Q&A 3단, Vocabulary Log, Order the Events, Grammar Hunt | 모든 장르 | 워크시트 |
| ② 산출 활동 | 3-Sentence Summary, Opinion Paragraph, Retell Relay, Letter to Character, Continue the Story, News Report, Tweet Translation | 내러티브·논설 | 워크시트 |
| ③ 협력·게임 | Jigsaw Reading, Hot Seat, Vocabulary Bingo, Quiz Quiz Trade, Information Gap, Find Someone Who, Running Dictation, Reader's Theater | 분할 가능 / 인물·정보 풍부 | 카드세트·보드 |
| ④ 프로젝트·심화 | Poster + Gallery Walk, Mini-Debate, Concept Map, Cross-Reading, PSA Script, 세특 연계 보고서 | 논쟁·확장 가능 | 그래픽조직자·슬라이드 |

## 중요 원칙

1. **활동 ≠ 평가**: 이 스킬은 학습 활동을 만든다. 정오답 채점이 아니라 참여·표현·협력을 본다. 산출물에 점수를 매기는 평가는 평가 루브릭만 첨부할 뿐, 자료 자체는 활동 진행에 최적화한다.
2. **본문 중심성 유지**: 어떤 활동이든 학생이 본문을 다시 들여다보게 만들어야 한다. 본문과 무관한 일반 토론으로 흐르지 않게 reference의 "본문 후크" 항목을 반드시 활용한다.
3. **현실적 차시 운영**: 50분 1차시를 채우려 하지 말 것. 25-30분 활동 + 도입·마무리 교사 시간이 현실적. 무리하게 5단계 활동을 우겨 넣으면 진행이 망가진다.
4. **한국 고교 교실 현실 반영**: 30명 학급, 6-8개 모둠, 영어 발화에 부담을 느끼는 학생 비율 고려. 교사용 가이드의 "예상 어려움" 섹션이 핵심이다.
5. **다른 스킬과 연계**: 산출 활동의 글쓰기 평가는 별도 진행 시 `writing-critic` 스킬, 시험 문항화는 `exam-paper-generator` 스킬, 세특 작성은 별도 워크플로로 분리한다.
