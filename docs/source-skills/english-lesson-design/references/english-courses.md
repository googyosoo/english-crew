# 영어과 대상 과목 구조 (조회로 확인한 사실만)

출처: `kr-curriculum-2022/data/고/영어.jsonl` (2026-10-04 확인). 문장은 여기에 옮기지 않는다. 인용은 항상 `lookup.py` 결과를 쓴다.

## 코드 구조

- `10공영1-01-NN` / `10공영1-02-NN`: 공통영어1 (고1). 01은 이해, 02는 표현 성취기준.
- `10공영2-01-NN` / `10공영2-02-NN`: 공통영어2 (고1).
- `12영Ⅰ-01-NN` / `12영Ⅰ-02-NN`: 영어Ⅰ (고2).
- `12영Ⅱ-01-NN` / `12영Ⅱ-02-NN`: 영어Ⅱ (고2).
- 같은 끝번호라도 과목마다 가리키는 내용이 다르다(예: 공통영어1과 공통영어2의 `01-07`). **과목과 코드를 함께** 확인한다(고유키는 `(교과, 코드)`).

## 건수와 구성

| 과목 | 이해(01) | 표현(02) |
|---|---|---|
| 공통영어1 | 8 | 8 |
| 공통영어2 | 8 | 9 |
| 영어Ⅰ | 8 | 8 |
| 영어Ⅱ | 8 | 9 |

- 태도 성격(포용, 존중, 협력) 성취기준은 성취수준이 A·C·E 세 단계만 있다. 해당 코드: `10공영1-01-08`, `10공영1-02-08`, `10공영2-02-09`, `12영Ⅰ-01-08`, `12영Ⅰ-02-08`, `12영Ⅱ-01-08`, `12영Ⅱ-02-09`. B·D를 만들어 채우지 않는다.
- 공통영어2의 `10공영2-02-05`는 두 출처의 문장이 달라(`statement_verified: false`, `needs_review`) 원문 대조가 필요하다.

## 과목 간 연속성에 쓰는 법

- 공통영어1 → 공통영어2는 이해 1~6번이 거의 같은 기능(세부 정보, 주제·요지, 추론, 논리 관계, 함축, 구조)을 다루고 수준 서술이 달라진다. 7번 이후는 내용이 다르다(공통영어2에는 매체 자료의 비판적 이해가 추가됨). 두 과목을 이어 설계할 때는 같은 기능에서 성취수준 서술문이 어떻게 달라지는지 `lookup.py --keyword`로 나란히 뽑아 비교한다.
- 영어Ⅰ → 영어Ⅱ도 같은 방식으로 비교한다. 새로 추가되는 기능(예: 설득, 서식 작성, 재구성 요약)은 조회로 찾는다.
- 비교 결과는 원문 인용으로 보여 주고, 해석은 따로 쓴다.
