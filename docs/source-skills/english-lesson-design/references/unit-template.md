# 단원 계획 틀 (영어과)

## A. 단원 개요

| 항목 | 내용 |
|---|---|
| 과목 / 학기 / 단원 | |
| 차시 수 / 수업 형태 | |
| 단원 핵심 질문(학생에게 던질 질문 1~2개) | |
| 이번 단원의 성취기준(조회 결과 그대로) | |
| 교사가 확인한 가정 | |

## B. 정렬표 (증거 먼저)

| 성취기준 | 학생이 보여 줄 증거 | 평가 방식 | 수준 구분의 핵심 | 다루지 않을 부분 |
|---|---|---|---|---|

점검 질문
1. 증거를 모으는 활동이 실제 수업 안에 있는가?
2. 이해 성취기준을 표현 활동으로 드러내게 할 때, 표현 실력이 이해 평가를 가리지 않는가?
3. 같은 성취기준을 평가하는 형성평가와 수행평가가 서로 다른 기준을 쓰고 있지 않은가?

## C. 차시별 계획

| 차시 | 학습 목표(1개) | 핵심 활동(학생이 하는 일) | 언어 초점(도구로서) | 증거 수집 | 피드백 |
|---|---|---|---|---|---|
| 1 | | | | | |

규칙
- 학습 목표는 학생이 할 수 있는 행동으로 쓴다(예: "~을 요약하여 말할 수 있다"). 성취기준 문장을 그대로 복사해 목표로 쓰지 않는다. 성취기준은 별도 칸에서 인용한다.
- 언어 초점은 1차시에 1~2개 이내로 제한한다.
- 학생 발화·작문 시간이 차시의 절반 이상이 되도록 한다. 안 되면 활동을 줄이고 교사 설명을 줄인다.

## D. 수준별 지원

| 구분 | 발판(지원이 필요한 학생) | 확장(심화 학생) |
|---|---|---|
| 이해 활동 | 핵심어 표시, 단락별 질문 | 필자 관점 비교, 근거 반박 |
| 표현 활동 | 문장 틀, 단어 은행, 모델 문장 | 조건 추가(논리 보강, 어조 조절) |

학생 개인 정보 없이 유형 단위로 쓴다.

## E. 피드백 설계

| 시점 | 방식 | 학생이 받는 것 | 다음에 바꿀 것 |
|---|---|---|---|
| 수업 중 | 순회 관찰, 짝 점검 | 즉시 한 가지 개선점 | |
| 수업 후 | 짧은 확인 과제 | 기준에 비춘 한두 줄 | 다음 차시 활동 조정 |
| 단원 말 | 자기평가 + 동료평가 | 기준표 기반 수정 기회 | 재확인 방법 |

피드백 원칙
- 점수보다 **기준에 비춘 다음 단계**를 준다.
- 한 번에 2가지 이내만 고치게 한다.
- 수정 기회를 준 뒤에는 **재확인** 단계를 둔다.
- 학생 개인 답안을 AI에 넣을 때는 실명·학번을 지우고 학교 지침을 따른다.

## F. 마무리

- 교사가 확인할 것 3가지
- 루브릭이 필요하면 `rubric-creator`에 넘길 입력: (성취기준, 과제 설명, 정렬표의 증거)
